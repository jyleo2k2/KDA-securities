> 최종 갱신: 2026-07-13

> **진입점**: 세션 시작 시 [CLAUDE.md](./CLAUDE.md)(Claude Code) / [AGENTS.md](./AGENTS.md)(Codex)가 자동 로드된다(30초 오리엔테이션, 두 파일 내용 동기화). 이 README는 전체 지도.

## 한 줄 정의

**"DC형 퇴직연금 계좌를 선택했지만 운용 방법을 모르는 이용자에게 계좌 운용 원리와 선택 기준을 쉽게 알려주는 AI 연금 운용 가이드."**

핵심 차별화: 상품을 대신 골라주거나 자동으로 운용하는 서비스가 아니라, DC형 가입자가 자신의 계좌를 이해하고 스스로 운용 결정을 내리도록 돕는 설명형 서비스.

## 확정된 핵심 결정 (2026-07 기준)

- **아이템**: DC형 퇴직연금 계좌 현황 이해 → 운용 방법 학습 → 성향별 자산배분 예시·시뮬레이션 → 스스로 다음 행동 선택
- **페르소나**: DC형 퇴직연금 계좌를 선택했지만 상품과 운용 방법을 몰라 현금성·저위험 자산에 방치한 이용자
- **차별화(재정의, 2026-07-13)**: **DC형 특화 × 쉬운 운용 교육 × 설명 가능한 시뮬레이션**. 키움 기존 AI 스택의 자동운용·상품제시 기능과 경쟁하기보다, DC형 가입자가 "왜 이 비중과 상품군을 검토해야 하는지" 이해하게 만드는 연금 운용 학습 레이어로 포지셔닝한다.
- **AI 설계**: 규칙 기반 엔진이 계산, LLM은 서술·Q&A만 (Explainable by Design) + 하네스 엔지니어링
- **계좌 투자 규칙(엔진 근거, 2026-07-10)**: DC형 퇴직연금은 **개별주식 불가·국내상장 ETF/펀드 중심·위험자산 한도 적용** → 교육 콘텐츠와 포트폴리오 예시의 후보 범위를 계좌 규칙 안으로 제한 ([pension-basics.md §4-1](./pension-basics.md))
- **산출물**: 모바일 중심 PWA + FastAPI + Claude API 하네스, 팀 ~5명(미정)
- **데이터**: 통합연금포털·KRX/OpenAPI 공개 데이터 + DC형 계좌 시나리오 목데이터 3종
- **개발 도구**: Claude Code + Codex 병행(진입점 `CLAUDE.md`/`AGENTS.md` 동기화). 도구별 로컬 강제(`.claude/settings.json` 등)는 서로 호환 안 됨 → **공용 강제는 CI로** (코드 생기면)
