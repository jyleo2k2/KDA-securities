# 팀원 시작 가이드 — AI 코딩 도구 5분 셋업

> 이거 하나면 된다. 위에서 아래로 따라 해라. 막히면 아무 줄이나 AI에게 붙여넣고 "이거 해줘"라고 해도 된다.

---

## 1. 하네스가 뭔가 (30초)

**AI = 천재 신입사원. 하네스 = 그 신입에게 주는 사내 규정집 + 권한카드 + 자동 체크리스트.**

- 신입(AI 모델)은 똑똑하지만 **우리 팀 규칙·맥락을 모른다.**
- 하네스 = 그 신입이 사고 안 치고 일 잘하게 **환경을 깔아주는 것** (규칙 문서 + 권한 + 자동검증).
- 공식: **에이전트 = 모델 + 하네스.** 모델은 못 바꾸니 우리가 손댈 건 하네스다.
- 핵심 한 줄: 규칙을 **'부탁'(프롬프트)이 아니라 '강제'(자동검증·권한)로** 만들면 진짜 하네스.

우리는 이 하네스를 문서로 팀에 깔아놨다. 아래 순서대로 하면 너도 그걸 쓰게 된다.

## 2. CLI 설치 (둘 중 하나만 골라도 됨)

먼저 **터미널**을 연다.
- Windows: 시작 → `PowerShell` 검색 → 실행
- Mac: `Cmd+Space` → `터미널` 검색 → 실행

명령을 붙여넣고(우클릭 또는 `Ctrl+V` / 맥은 `Cmd+V`) Enter. 한 줄씩.

### Claude Code (앤트로픽) — 권장, 설치 제일 쉬움
- 공식 설치 문서 그대로 따르기 (별도 프로그램 불필요): https://code.claude.com/docs/en/setup
- 또는 npm으로 (이땐 Node.js 18+ 필요, **sudo 붙이지 말 것**):
  ```
  npm install -g @anthropic-ai/claude-code
  ```
- 설치 후 터미널에 `claude` 입력 → 시작. 처음엔 로그인(유료 계정) 또는 API 키.

### Codex (오픈AI)
- Windows (PowerShell):
  ```
  powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
  ```
- Mac / Linux:
  ```
  curl -fsSL https://chatgpt.com/codex/install.sh | sh
  ```
- 설치 후 터미널에 `codex` 입력 → 시작. ChatGPT 계정 로그인 또는 API 키.
- 공식 문서: https://developers.openai.com/codex/cli

### (npm 경로 택했을 때만) Node.js
- LTS 설치: https://nodejs.org  →  확인: `node --version`

> 요금·플랜은 자주 바뀐다. 결제 전 공식 페이지에서 최신 확인:
> Claude → https://claude.ai/upgrade · Codex → https://chatgpt.com/codex/pricing

## 3. 카파시(Karpathy) 스킬 설치 — AI 실수 줄이는 규칙팩

AI가 자주 하는 실수(멋대로 가정·과설계·엉뚱한 수정·모호한 작업)를 줄여주는 규칙 모음.
**Claude Code를 켠 상태에서** 아래 두 줄을 순서대로 입력한다 (모든 프로젝트에 한 번에 적용됨):

```
/plugin marketplace add forrestchang/andrej-karpathy-skills
/plugin install andrej-karpathy-skills@karpathy-skills
```

> 이 프로젝트에만 적용하고 싶으면 대신 (터미널에서):
> `curl https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md >> CLAUDE.md`

## 4. 어떤 문서를 AI에게 먹이나 (중요)

새 대화 시작 시, AI가 **우리 팀 맥락을 알도록** 아래 파일을 읽힌다. 순서대로:

1. `CLAUDE.md` (또는 Codex면 `AGENTS.md`) — 세션 시작 시 자동 로드되는 진입점
2. `docs/team/_공통_AI규칙.md` — 팀 공통 규칙(헌장). **모든 AI가 처음 읽는 고정 규칙**
3. `{내 이름}-담당업무.md` — 내가 맡은 폴더·할 일
4. `docs/ARCHITECTURE.md` — 전체 구조

> 1번(`CLAUDE.md`/`AGENTS.md`)은 도구가 **자동으로** 읽는다. 2~4번은 온보딩 프롬프트(아래)로 직접 읽힌다.

---

## 5. 프롬프트 먹이는 법 (실제 작업 흐름)

**대화 시작 시 딱 한 번 — 온보딩 프롬프트 (복붙):**
```
너는 우리 팀 프로젝트를 돕는다. 나는 {내 역할} 담당이야. 설명은 쉽고 명확하게.
먼저 아래 파일을 읽고 "읽었음"과 함께 ① 내가 할 일 ② 하면 안 되는 것
③ 꼭 지킬 핵심 규칙을 정리해줘. 아직 만들지 마.
읽을 파일: 1.CLAUDE.md 2.docs/team/_공통_AI규칙.md 3.{내 이름}-담당업무.md 4.docs/ARCHITECTURE.md
```

**그 다음 실제 작업 — 한 번에 하나씩:**
```
[작업] {무엇을 만들지 — 파일 경로 포함}
[제약] {지켜야 할 것}
[검증] {스스로 확인할 기준}
[산출물] 계획 먼저 보여주고, 내가 "진행해" 하면 만들어.
```

**작동 방식은 딱 4단계:** 온보딩 붙여넣기 → 작업 블록 붙여넣기 → AI가 계획 보이면 "진행해" → 자가검증.

## 6. 막히면 그대로 붙여넣기

- 쉽게 설명: `방금 한 걸 누구나 알아듣게 쉽게 설명해줘.`
- 가짜 값 방지: `이 값 추측이야? 추측이면 TODO로 바꿔줘.`
- 검증: `방금 만든 걸 실제로 실행해서 결과를 보여줘.`
- 한 번에 하나: `지금은 [이것]만 하자. 다른 건 건드리지 마.`
- 설치·로그인 막힘: 위 공식 문서 링크를 AI에 주고 `이 문서 보고 단계별로 알려줘.`
