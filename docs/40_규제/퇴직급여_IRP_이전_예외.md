# 퇴직급여의 IRP 이전 — 원칙과 일시금 예외 확인

> 문서 기준일: 2026-07-20
> 적용 범위: 퇴직 시 DB형·DC형 퇴직급여를 개인형퇴직연금(IRP) 계정으로 이전하는 일반 원칙. 금융회사 사이에서 보유 상품을 옮기는 ‘실물이전’과는 다른 절차다.

## 1. 퇴직급여 이전과 실물이전은 다르다

- **퇴직급여의 IRP 이전**: 퇴직 시 발생한 DB형·DC형 급여를 본인 명의 IRP 계정으로 받는 절차다.
- **실물이전**: 이미 운용 중인 퇴직연금 계좌의 보유 상품을 다른 금융회사로 옮기는 절차다.

두 절차는 적용 시점과 예외 사유가 다르므로, 질문에 ‘퇴직 직후 급여 수령’인지 ‘금융회사 변경’인지가 명확해야 한다.

## 2. IRP 이전이 원칙인 상황과 예외

퇴직급여는 원칙적으로 가입자가 지정한 IRP 계정 등으로 이전해 지급한다. 다만 다음과 같이 법령상 예외가 있을 수 있다.

- 55세 이후 퇴직해 급여를 받는 경우
- 급여를 담보로 받은 대출금 등을 상환하는 경우
- 급여가 법령상 소액 기준 이하인 경우
- 사망, 출국 등 법령에서 정한 특별한 사유가 있는 경우
- 다른 법령에 따라 급여의 전부 또는 일부를 공제해야 하는 경우

예외 해당 여부와 필요한 서류는 퇴직 시점의 법령·회사·퇴직연금사업자 안내를 기준으로 확인한다. 이 문서는 일시금 수령의 세금 결과를 계산하지 않는다.

## 3. 챗봇 답변의 범위

챗봇은 이전 원칙과 확인 항목을 설명한다. 개인별 퇴직일, 나이, 급여액, 담보대출 여부, 국외 출국 사유가 확인되지 않은 상태에서는 특정 예외를 단정하지 않는다.
