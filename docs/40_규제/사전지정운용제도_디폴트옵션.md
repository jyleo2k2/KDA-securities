# 사전지정운용제도(디폴트옵션) — 적용 절차와 확인 항목

> 문서 기준일: 2026-07-16  
> 적용 범위: DC형과 IRP의 사전지정운용제도. 개별 상품의 수익·손실을 보장하거나 특정 상품을 권유하지 않는다.

## 1. 디폴트옵션이란

사전지정운용제도(디폴트옵션)는 가입자가 일정 기간 운용지시를 하지 않을 때를 대비해, 미리 정해 둔 운용방법으로 적립금을 운용하는 제도다. DC형과 IRP에서 사용할 수 있으며, 적용 대상 운용방법은 제도 절차에 따라 승인된 상품·포트폴리오여야 한다.

디폴트옵션은 “아무 상품이나 자동 매수”하는 기능이 아니다. 가입자가 사전에 운용방법을 선택하고, 운용지시가 없을 때 적용할 수 있도록 통지·확인 절차를 거치는 구조다.

## 2. 적용 전에 확인할 것

1. 계좌가 DC형 또는 IRP인지 확인한다. 연금저축에는 같은 제도를 적용하지 않는다.
2. 사전지정한 운용방법의 이름, 위험등급과 자산구성을 확인한다.
3. 원금보장 여부와 손실 가능성을 구분한다. 디폴트옵션이라고 해서 수익이나 원금이 보장되는 것은 아니다.
4. 과거 수익률의 기준기간과 비용을 함께 확인한다. 과거 성과는 미래 성과를 보장하지 않는다.
5. 적용, 변경, 해지 방법과 금융회사의 통지 내용을 확인한다.

## 3. 위험자산 한도와의 관계

DC형·IRP의 일반 운용에는 위험자산 한도 규칙이 적용될 수 있다. 다만 승인된 디폴트옵션은 일반 위험자산 한도와 별도의 예외 판정이 필요하다. 따라서 답변은 `계좌 유형 → 상품이 승인된 디폴트옵션인지 → 해당 상품의 위험등급·구성 → 예외 적용 여부` 순서로 확인한다.

## 4. 챗봇 답변의 경계

- 챗봇은 제도와 확인 항목을 설명한다.
- 사용자의 실제 계좌에 어떤 디폴트옵션이 지정되어 있는지는 계좌 화면 또는 금융회사 안내문 없이는 알 수 없다.
- 상품별 수익률·비용은 공식 공시의 기준일을 함께 제시하고, 특정 성과를 약속하지 않는다.
