# 퇴직연금 미납 부담금 — 확인·지연이자·보호 기준

> 문서 기준일: 2026-07-20
> 적용 범위: 사용자가 납입해야 하는 퇴직연금 부담금이 제때 납입되지 않은 상황의 일반 안내. 개별 체불·도산 사건의 법률 판단이나 청구 절차를 대신하지 않는다.

## 1. 이미 적립된 금액과 미납 부담금은 다르다

퇴직연금 계정에 이미 적립된 금액은 사업장 운영자금과 분리해 관리된다. 반면 사용자가 아직 납입하지 않은 부담금은 계좌에 들어오기 전의 미납 상태다. 따라서 가입자는 적립금 화면뿐 아니라 회사 부담금의 납입 예정일과 실제 납입 여부를 함께 확인해야 한다.

## 2. 미납이면 지연이자가 문제된다

사용자가 정해진 납입기일까지 부담금을 내지 않으면 법령상 지연이자가 적용될 수 있다. 정확한 기산일, 이율, 적용 제외 사유와 청구 방법은 퇴직연금규약·계약과 최신 법령을 함께 확인해야 한다.

## 3. 퇴직급여 등의 보호

법은 퇴직급여와 일정한 미납 부담금·지연이자에 우선변제 규정을 둔다. 다만 담보권 등 다른 권리와의 관계, 실제 도산 절차, 체불임금과의 우선순위는 사건별로 달라질 수 있다. 회사의 지급 문제가 발생했다면 퇴직연금사업자·고용노동부 상담창구·전문가를 통해 사실관계와 청구 절차를 확인한다.

## 4. 답변에 필요한 확인 질문

1. 가입한 퇴직연금 제도는 무엇인가?
2. 회사 부담금의 납입 예정일과 마지막 실제 납입일은 언제인가?
3. 퇴직 전인지, 퇴직 후 급여 지급 단계인지?
4. 회사의 도산·회생·임금체불 절차가 진행 중인지?
