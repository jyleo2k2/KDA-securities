# 보다 가까워지는 연금

> 연금 가이드 기능 아이디어 정리

## 1. 연금 관심 및 운용 참여 유도

- **"그때 샀더라면"**  
  과거의 특정 시점에 연금 상품이나 자산을 운용했다면 결과가 어떻게 달라졌을지 보여주는 교육용 비교 기능

- **동일 연령대 비교**  
  같은 연령대 이용자와 납입액, 운용 상태 등을 비교하여 현재 상태를 쉽게 이해하도록 돕는 기능

두 기능 중 하나만 선택했으면 좋겠습니다. 둘 다 선택하면 기능이 너무 많은 것 같습니다.


## 2. 연금 설명

- **현재 상태**  
  잔액, 납입액, 수익률, 상품별 비중, 현금성 자산, 위험자산 비중, 총비용을 보여준다.

- **문제 진단**  
  장기 미운용, 과도한 현금성 자산, 특정 자산 쏠림, 상품 중복, 목표 비중 이탈 여부를 확인한다.

- **판단 근거**  
  현재 상태가 왜 문제인지 설명하고, 적용된 규칙, 기준일, 데이터 출처를 함께 표시한다.

- **교육용 대안**  
  투자 성향별 자산군 비중 예시와 각 자산이 포트폴리오에서 담당하는 역할을 설명한다.

- **위험 설명**  
  예상 수익만 강조하지 않고 손실 가능 범위, 스트레스 상황, 원금 보장 및 예금자 보호 여부를 안내한다.

- **비용 및 거래 조건**  
  총보수, 매매 비용, 환매 기간, 만기, 환율 위험, 금리 위험, 신용 위험을 설명한다.

- **전후 비교**  
  현재 상태를 유지하는 경우와 자산 비중을 변경하는 경우의 장기 적립 결과 및 하락장 결과를 비교한다.

- **행동 안내**  
  이용자가 실제 금융 앱에서 확인하거나 변경해야 할 다음 단계를 안내한다.

- **한계 표시**  
  목데이터 사용 여부, 교육용 예시임을 명시하고, 미래 성과가 보장되지 않으며 실제 주문을 지원하지 않는다는 점을 표시한다.

- **설명형 Q&A**  
  답변마다 적용된 수치, 규칙, 공식 출처를 함께 보여준다.

## 3. 상품 후기

- 전문가 후기 제공
- 실제 구매자 후기 제공
- 후기의 검증 방식과 광고성 콘텐츠 표시 기준은 추가 검토가 필요하다.

전문가 후기를 제공할지, 실제 구매자 후기를 제공할지, 혹은 아예 후기를 없앨지 고민중입니다.

## 4. 연금 퀴즈 또는 미션

- 연금 제도와 운용 원리를 가볍게 익힐 수 있는 퀴즈를 제공한다.
- 퀴즈나 미션 참여에 적립 혜택을 연계할 수 있는지 검토한다.

퀴즈나 미션도 둘 중 하나만 선택했으면 좋겠습니다.
