# 목데이터 생성 및 참고자료

> **요약:** 실제 고객정보를 사용하지 않고 고정 시드(`20260714`)로 생성한 사용자 10,000명의 완전 합성 데이터다. 계좌는 **DC·IRP·연금저축펀드만** 포함하며, 연령 분포·계좌 평균 적립액·과거 1년 수익률의 기준점은 공공기관 및 공식 연구자료를 참고했다. 공개되지 않은 개인별 편차, 계좌 조합, 월 납입액과 세부 자산배분은 서비스 시연을 위한 모델 가정이다. 모든 데이터 행은 `data_kind=MOCK`으로 표시한다.
>
> **주요 참고자료:** 보험연구원 연구보고서 2025-20, 고용노동부·금융감독원 2025 퇴직연금 투자 백서, 통계청 2024 퇴직연금통계, 금융위원회·금융감독원 2025 연금저축 투자 백서.

## 1. 생성 결과

| 구분 | 건수 |
|---|---:|
| 합성 사용자 | 10,000명 |
| 계좌 | 18,052개 |
| DC | 7,317개 |
| IRP | 5,538개 |
| 연금저축펀드 | 5,197개 |
| 계좌별 보유자산 | 85,063건 |

생성 파일은 다음과 같다.

- `data/mock/users.csv`: 연령, 투자성향, 목시나리오가 포함된 사용자
- `data/mock/accounts.csv`: DC·IRP·연금저축펀드 계좌와 적립액·납입액·자산 비중·과거 수익률
- `data/mock/holdings.csv`: 국내주식·글로벌주식·채권·원리금보장·현금성 자산 구성
- `data/mock/sources.json`: 통계 출처와 모델 가정 식별자
- `data/mock/validation_summary.json`: 생성 건수, 평균, 표준편차와 제약조건 검증 결과

## 2. 생성 방식

1. 공식 조사자료의 연령대 비중을 기준으로 20대·30대·40대·50세 이상 사용자 수를 배분했다.
2. 서비스 검증에 필요한 `DC 방치형`, `세액공제 후 미운용형`, `중복·위험 편중형` 시나리오를 각각 40%·30%·30%로 배정했다.
3. 계좌별 적립액은 연령대별 평균에 맞춘 로그정규분포로 생성했다. 공개 표준편차가 없어 분산값은 모델 가정으로 관리한다.
4. DC·IRP·연금저축펀드의 과거 1년 수익률 평균은 2025년 공식 통계에 맞췄다. 이는 미래 기대수익률이나 수익 보장값이 아니다.
5. DC와 IRP의 일반 위험자산 비중은 계좌별 70%를 넘지 못하도록 생성 단계와 검증 단계에서 이중 확인한다.
6. 연금저축펀드에는 DC·IRP용 원리금보장상품을 생성하지 않는다.
7. 같은 시드를 사용하면 같은 결과가 생성되도록 재현성을 보장한다.

## 4. 모델 가정과 사용 제한

공개 교차통계가 부족해 다음 항목은 `ASSUMPTION_V1`로 구분했다.

- 사용자별 계좌 보유 조합
- IRP·연금저축펀드의 연령대별 적립액 곡선
- 개인별 적립액·수익률의 표준편차와 월 납입액
- 국내주식·글로벌주식·채권·원리금보장·현금의 세부 비중
- 투자성향과 목시나리오 분포

따라서 이 데이터는 화면 개발, 규칙 엔진 검증, 데모와 테스트에만 사용한다. 실제 고객 분석, 영업자료, 수익 예측 또는 투자성과 보장 근거로 사용하면 안 된다.

## 5. 재생성 및 검증

```powershell
uv --cache-dir "$env:TEMP\codex-uv-cache" run python scripts/generate_mock_pension_data.py
uv --cache-dir "$env:TEMP\codex-uv-cache" run python -m unittest tests/test_mock_pension_data.py
```

검증 항목은 다음과 같다.

- 사용자 10,000명 및 사용자 ID 유일성
- 모든 사용자가 하나 이상의 계좌 보유
- 계좌 유형이 DC·IRP·연금저축펀드로만 구성
- DC·IRP 위험자산 비중 70% 이하
- 연금저축펀드 원리금보장상품 0건
- 계좌·보유자산 비중 합계 100%
- 계좌 잔액과 보유자산 금액 합계 일치
- 동일 시드의 결과 재현성
