# RAG 지식 코퍼스 5종 확충 설계

## 목표

기존 승인 문서 5건이 주로 연금계좌 규칙에 집중된 문제를 보완한다. 한국거래소·고용노동부·국세청·금융위원회 공식 원문만 근거로 사용자 질문에 답할 검증 문서 5건을 추가한다.

## 문서와 경계

| 경로 | 범위 | 기준일 |
|---|---|---|
| `docs/20_리서치/ETF_비교지표_읽기.md` | ETF의 NAV·iNAV·괴리율·추적오차·비용·유동성·분배금 | 2026-07-18 공식 페이지 검증일 |
| `docs/20_리서치/퇴직연금_2025_운용현황.md` | 2025년 퇴직연금 적립금·운용유형·과거 수익률 통계와 해석 한계 | 2025-12-31 통계 기준일 |
| `docs/40_규제/연금수령_과세.md` | 연금수령·연금외수령, 재원별 과세와 공식 확인 항목 | 2026-07-18 국세청 페이지 검증일 |
| `docs/40_규제/퇴직연금_실물이전.md` | 동일 제도 간 실물이전 절차·대상·제외·사전조회 | 2025-07-21 사전조회 시행일 |

문서는 사용자용 설명만 담는다. 팀 전략, 경쟁사 분석, 목데이터, 개인화 추천, 미래수익 예측은 포함하지 않는다. 공식 원문에 없는 해석은 추가하지 않고, 시점에 따라 달라질 수 있는 규칙은 기준일과 확인 필요성을 함께 표시한다.

## 등록과 검색 품질

각 문서를 `data/knowledge/approved_documents.json`에 기존 형식으로 등록한다. `source_url`은 `project://<path>`, 해시는 UTF-8 `strip()` 본문의 SHA-256, 데이터 경계는 `verified_knowledge`로 고정한다.

`data/search_quality/knowledge_v1.json`에는 문서별 대표 질문 1건을 추가하여 ETF 비교, 과거 운용현황, 연금수령 과세, 실물이전, 예금자보호가 각각 해당 문서를 찾는지 검증한다.

## 검증

1. 매니페스트가 10건과 신규 경로 5건을 반환한다는 테스트를 먼저 추가하고 실패를 확인한다.
2. 문서와 매니페스트를 추가한 뒤 대상 테스트를 통과시킨다.
3. `load_approved_documents()`로 SHA-256·허용 경로·개인정보·청크 생성을 검증한다.
4. 전체 `uv run pytest`를 실행한다.
5. 원격 임베딩 적재는 수행하지 않고 PR에 이재용 직접 실행 필요를 기록한다.
