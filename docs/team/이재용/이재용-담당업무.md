# 이재용 — 담당업무 (프로젝트 총괄·AI 서비스 아키텍처)

## 1. 담당 역할

### 프로젝트 총괄·AI 서비스 아키텍처 통합

서비스 전체 기술 구조를 설계하고 규칙 엔진·데이터·챗봇·프론트엔드가 일관된 계약으로 연결되도록 통합했다. 핵심 기능을 직접 구현하는 동시에 팀원 산출물의 코드 정합성, 보안, 테스트, PR 병합과 최종 시연 품질을 관리했다.

## 2. 발표자료 카드 문구

**이재용　총괄·AI 서비스 아키텍처**
전체 아키텍처 · 규칙 엔진·LLM 분리 · 챗봇/RAG · 서비스 통합·검증

## 3. 주요 담당 업무

### 프로젝트 아키텍처 및 기술 기준 수립

- React → FastAPI → 규칙 엔진·데이터의 단방향 구조 설계
- 계산은 규칙 엔진, 설명은 LLM이 담당하는 Explainable by Design 원칙 수립
- 실데이터·목데이터·RAG 지식의 사용 경계와 API 계약 정의
- 아키텍처·코드베이스 지도·공통 개발 규칙 등 기술 문서 관리
- 팀별 작업 경계, 공유 파일 충돌 방지, PR 검토·머지 체계 구축

### 백엔드·데이터 기반 구축

- FastAPI 앱 구조와 엔진·공시·검색 API 골격 구현
- Supabase 초기 스키마, RLS, 사용자 인증 및 대화 저장 구조 구축
- FSS 공시와 NAVER 뉴스 수집·저장 파이프라인 구현
- ETF 유니버스와 총수익 이력의 원격 Supabase 통합
- 투자성향 저장·조회 API와 사용자별 데이터 연결 구현

### 규칙 엔진 및 연금 계산 기능 구현

- 성향 분석, 계좌별 진단, 통합 집계, 적립 시뮬레이션 등 초기 엔진 골격 구현
- DC·IRP 위험자산 70% 한도와 연금저축 적격성 분리 적용
- 연차별 적립금과 월 수령액을 계산하는 연금계산기 엔진 구현
- 세액공제·연금외수령 계산 API와 화면 표시 계약 연결
- 교육용 ETF 포트폴리오의 DB·로컬 결과 동등성과 위험한도 검증

### AI 챗봇·RAG 고도화

- pydantic-ai와 Claude 기반 설명형 챗봇 구조 도입
- 엔진에 없는 숫자나 위험 표현을 차단하는 내레이터 가드 구현·보강
- BGE-M3 기반 공식 문서 RAG와 하이브리드 검색 체계 구축
- SSE 스트리밍, 답변 캐시, 선응답·후내레이션 구조로 응답 속도 개선
- 추천 카드·시각화·후속 질문과 문맥 연결 기능 구현
- 챗봇 답변을 간결한 해요체와 결론 우선 구조로 개선

### 프론트엔드 및 시연 흐름 통합

- React PWA 초기 골격과 백엔드 API 타입 계약 구축
- Supabase 로그인·로그아웃·세션 게이트 연결
- 저장된 투자성향의 재접속 유지와 사용자별 화면 데이터 전환 구현
- 타 고객 포트폴리오 비교 화면과 챗봇 추천 UX 개선

### 통합 검증 및 프로젝트 운영

- 팀원별 PR의 계약 변경, 보안, 테스트 결과와 코드 정합성 검토
- 병렬 개발을 위한 브랜치·워크트리·파일 담당 관리 체계 구축
- 충돌 해결과 최신 `main` 기준 회귀 테스트 수행
- 백엔드·프론트·Supabase를 연결한 전체 시연 흐름 QA
- 구현 상태와 남은 의사결정을 기술 문서에 지속적으로 반영

## 4. 발표 멘트

저는 프로젝트 총괄로서 서비스 전체 아키텍처를 설계하고, 규칙 엔진과 데이터, AI 챗봇, 프론트 화면이 하나의 일관된 서비스로 동작하도록 통합했습니다. 계산은 규칙 엔진이 담당하고 LLM은 검증된 수치만 설명하도록 구조를 분리했으며, FastAPI와 Supabase 기반의 데이터·인증 구조, 공식 문서 RAG, 챗봇 스트리밍과 안전장치를 구현했습니다.

또한 연금계산기, 투자성향 저장, 로그인과 계좌 연동 동의, 사용자별 홈 화면과 벤치마크 기능을 실제 시연 흐름으로 연결했습니다. 각 팀원의 개발 결과가 공통 API와 데이터 계약에 맞는지 검토하고, 테스트·보안·충돌 해결과 최종 PR 병합을 담당해 전체 서비스의 완성도와 코드 정합성을 관리했습니다.

## 5. 한 문장 요약

규칙 엔진·데이터·AI 챗봇·프론트엔드의 전체 구조를 설계하고, 각 기능이 실제 서비스와 시연 흐름으로 안정적으로 연결되도록 구현·통합·검증한 기술 총괄이다.

## 개발 작업 경계

- 전 영역의 구조·계약·품질을 감사하며 모든 PR의 최종 머지 권한을 가진다.
- 루트 `AGENTS.md`·`CLAUDE.md`는 이재용 전용 잠금 파일이며 `main` 직접 push는 하지 않는다.
- 다른 팀원 폴더 수정이 필요하면 담당자와 합의하고 PR로 반영한다.
