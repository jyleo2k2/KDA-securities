# 이재용 — 담당업무 (총괄)

## 담당 폴더 / 경계
- 전용 폴더 없음 — **전 영역 최고 권한**. 전체 아키텍처·코드 정합성 검토, 팀원 산출물 감사가 주 업무.
- **진입점 잠금**: [CLAUDE.md](../../../CLAUDE.md)·[AGENTS.md](../../../AGENTS.md)는 이재용만 수정한다. 로컬에 `.claude/.owner-verified` 마커가 있는 환경(이재용 개인 PC)에서만 편집 가능 — PreToolUse 훅이 강제한다(`.claude/settings.json`).
- **머지 승인**: 모든 PR의 최종 머지 권한. `main` 직접 push는 이재용도 하지 않는다(헌장 §2).
- 다른 팀원 폴더는 읽기 자유. 수정이 필요하면 담당자와 합의 후 PR(헌장 §2 "폴더 = 담당 경계" 준수 — 총괄도 예외 아님).
