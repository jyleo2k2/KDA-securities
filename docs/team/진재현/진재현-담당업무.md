# 진재현 — 담당업무 (프론트엔드·서비스 UI)

## 1. 담당 역할

### 프론트엔드·서비스 화면 구현

React PWA 기반 사용자 화면을 구현하고 백엔드 API·Supabase 인증 흐름이 실제 앱 화면에서 자연스럽게 이어지도록 연결했다. 로그인부터 홈, 챗봇, 연금계산기, 벤치마킹 화면까지의 사용자 경험과 UI 품질을 담당했다.

## 2. 발표자료 카드 문구

**진재현　프론트엔드·서비스 UI**
React PWA · 로그인/온보딩 · 챗봇·홈 화면 · 데모 UX

공간이 부족한 경우:

**진재현　프론트엔드·UI/UX**
React PWA · 화면 구현 · 서비스 흐름 연결

## 3. 주요 담당 업무

### React PWA 기반 프론트엔드 화면 구현

- React·TypeScript·Vite 기반 모바일 웹 화면 구성
- 홈, 연금가이드, 챗봇, 프로필 등 서비스 화면 UI 구현
- 모바일 화면 레이아웃·폰트·컴포넌트 스타일 개선

### 로그인 및 온보딩 흐름 연결

- 로그인 인트로, 로그인 폼, 로그인 성공 화면 구성
- 연금계좌 연동 동의 및 투자성향 진단 화면 흐름 연결
- Supabase 인증 상태에 따라 화면이 전환되도록 프론트 연결

### 홈 화면 및 주요 기능 UI 구현

- 메인 홈 화면, 연금 자산 요약, 도넛 차트, 전략 카드 구성
- 세액공제 계산기·전략 상세·이용자 Pick 화면 이동 연결
- 연금계좌 연동과 투자성향 결과를 홈 화면 경험으로 연결

### 챗봇 화면 및 데모 UX 개선

- 챗봇 프론트엔드 연결과 대화 화면 스타일 개선
- 챗봇 폰트와 대화 UI 조정
- 대화 기록, 새 대화 등 사용 흐름을 화면에 반영
- 화면 간 이동, 버튼, 동의 게이트 등 사용자 흐름 점검
- 디자인 시안에 맞춘 화면 테마·컴포넌트 수정과 프론트 빌드 오류 해결

## 4. 발표 멘트

저는 React PWA 기반의 프론트엔드 화면 구현을 담당했습니다. 로그인과 연금계좌 연동, 투자성향 진단 이후 홈 화면으로 이어지는 사용자 흐름을 구성했고, 챗봇과 연금계산기, 전략 상세, 이용자 벤치마킹 기능이 자연스럽게 연결되도록 구현했습니다.

또한 모바일 환경에서 보기 편하도록 홈 화면의 자산 요약, 도넛 차트, 카드형 콘텐츠와 챗봇 UI를 개선했습니다. 백엔드와 Supabase 인증 정보를 화면에 연결하고, 실제 시연 과정에서 화면 이동과 버튼 동작을 점검하며 데모 UX를 보완했습니다.

## 5. 한 문장 요약

React PWA 기반의 서비스 화면을 구현하고 로그인·온보딩·챗봇·홈 화면을 연결해 실제 시연 가능한 사용자 경험을 완성했다.

## 개발 작업 경계

- 주 작업 경로는 `frontend/`이며 최호택과 공유하므로 화면·컴포넌트 단위 claim을 먼저 확인한다.
- 엔진 계산과 DB 직접 접근은 하지 않고 백엔드 API 계약의 검증된 값을 표시한다.
