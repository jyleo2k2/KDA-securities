# 김태형 — 담당업무 (알고리즘 · 규칙 엔진)

## 담당 폴더 / 경계
- 내 폴더: `backend/app/engine`(연금계좌 운용 알고리즘·규칙 엔진 6모듈 + 전략). 이 안에서만 작업.
- 엔진은 **순수 함수로 유지**하며 FastAPI·Supabase·LLM에 의존하지 않는다([아키텍처.md §1](../../30_스펙/아키텍처.md#1-확정-스택과-단방향-의존)). 외부 호출·DB 접근이 필요하면 이호연(백엔드)과 계약을 맞춰 인터페이스만 노출한다.
- 계좌별 규칙 혼합 금지: DC형·IRP 위험자산 70% 한도와 연금저축 별도 적격성 규칙을 섞지 않는다(헌장 §1).
- 공유 계약(엔진 I/O 타입) 변경 시 PR에 "계약 변경" 명시.
