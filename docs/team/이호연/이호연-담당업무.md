# 이호연 — 담당업무 (팀장 · 챗봇·백엔드)

## 담당 폴더 / 경계
- 내 폴더: `backend/app`(단, `backend/app/engine`은 김태형 담당 — 제외). 실질적으로 `backend/app/api/`·`backend/app/chat/`·`backend/app/ingestion/`·`backend/app/retrieval/`.
- 이 안에서만 작업. 공유 계약(REST 스키마·엔진 I/O 타입) 변경 시 PR에 "계약 변경" 명시.
- `backend/app/engine`(김태형 담당)을 직접 고치지 않는다 — 엔진 결과가 필요하면 engine의 공개 함수/도구 인터페이스만 호출한다([아키텍처.md §1](../../30_스펙/아키텍처.md#1-확정-스택과-단방향-의존): FastAPI → engine 단방향).
