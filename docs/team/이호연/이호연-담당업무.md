# 이호연 — 담당업무 (조장·챗봇 백엔드)

## 1. 담당 역할

### 조장·챗봇·백엔드 총괄

FastAPI 기반 백엔드와 연금 챗봇의 질의 처리 구조를 담당했다. 뉴스·ETF 테마·연금계좌·세액공제 질문을 적절한 도구와 데이터 경로로 연결하고, 규칙 엔진의 계산 결과를 챗봇이 설명하도록 설계했다. ETF 테마 콘텐츠 검토·승인과 기능 통합도 조율했다.

## 2. 발표자료 카드 문구

**이호연　조장·챗봇 백엔드**
뉴스·ETF 테마·연금계좌 챗봇 도구 설계 · 세액공제 계산 연동 · 데이터 검증·서비스 통합

공간이 부족한 경우:

**이호연　챗봇·백엔드 담당**
연금 질문 도구 · ETF 테마 · 세액공제 계산

## 3. 주요 담당 업무

### 챗봇 백엔드 및 도구 설계

- FastAPI 기반 챗봇 API와 질의 분류·응답 생성 흐름 구현
- 뉴스, ETF 테마, 연금계좌 제도·규칙, 세액공제 질문별 도구 설계·등록
- LLM이 금융 수치를 직접 계산하지 않고 규칙 엔진·공식 데이터 조회 결과만 설명하도록 구성
- 질문 의도에 따라 뉴스 조회, ETF 테마 탐색, 연금계좌 안내, 세액공제 계산으로 안전하게 라우팅
- 추천 카드와 후속 질문을 연결해 자연스러운 추가 탐색 지원

### 증시 뉴스 챗봇 기능

- NAVER 뉴스 수집 데이터를 바탕으로 최근 증시 뉴스를 조회하는 기능 구현
- 기사 원문 기반 3줄 요약, 중복 제거, 시장 관련성 점수, 뉴스 선별 정책 적용
- 뉴스 질문 이후 후속 대화를 이어갈 수 있도록 조회 경로와 응답 흐름 정리
- 일일 뉴스 수집 자동화와 뉴스 데이터 품질 검증 흐름 보완

### ETF 테마 챗봇 기능

- 사용자 관심 주제에 맞는 ETF 테마 안내 도구와 추천 흐름 설계
- ETF 테마 카탈로그, 상품 설명, 구성종목 근거, 적격성·검증 상태 연결
- 계좌 적격성, 투자성향, 검증 근거를 함께 확인하는 교육형 안내 구성
- 채권 테마 추가와 ETF 테마 답변·데이터 품질 게이트 개선
- ETF 테마 자료의 검토·승인 범위 관리

### 연금계좌·세액공제 계산 로직 연결

- 연금저축과 IRP의 납입액, 소득 기준, 공제 한도를 반영하는 계산 흐름 설계
- 챗봇이 질문에서 필요한 정보만 구조화해 규칙 엔진에 전달하도록 구성
- 제도 설명은 공식 근거, 금액 계산은 규칙 엔진으로 분리
- 정보가 부족한 연금외수령 질문에서 확정 수치를 만들지 않고 가정과 검토 사항을 안내
- 연금계좌 규칙, 계좌별 차이, 세액공제 답변의 정확성과 설명 가능성 보완

### 백엔드·데이터·인증 통합 및 조장 역할

- 챗봇 대화 저장, 사용자 문맥, 뉴스·ETF 데이터 조회를 백엔드에서 연결
- Supabase 마이그레이션을 활용해 뉴스 선별 상태, ETF 검증 정보, 데모 사용자 재무 문맥 연결
- 로그인과 사용자별 챗봇 이용 흐름을 연동하고 프론트엔드 API 계약 조율
- 챗봇·ETF 기능의 회귀 테스트와 통합 검증 수행
- 프로젝트 초기 기획과 사용자 여정 정리, 팀원 작업 통합, 백엔드 계약과 콘텐츠 검토 기준 조율
- Windows 원클릭 실행 환경 구성과 메인 브랜치 통합 지원

## 4. 발표 멘트

챗봇과 백엔드 영역을 중심으로 서비스 기능을 통합했습니다. 특히 사용자가 많이 질문할 수 있는 증시 뉴스, ETF 테마, 연금계좌 제도, 세액공제 영역을 각각 도구로 설계하고 챗봇에 연결했습니다.

세액공제는 사용자의 연금저축·IRP 납입액과 소득 기준을 바탕으로 규칙 엔진이 계산하도록 설계했고, 챗봇은 계산 결과와 근거를 쉽게 설명하도록 구성했습니다. 또한 ETF 테마 기능에서는 상품 정보와 검증 근거, 계좌 적격성을 함께 확인하도록 해 단순 추천이 아닌 교육형 안내가 되도록 구현했습니다. 백엔드 API와 프론트엔드 연결, ETF 콘텐츠 검토, 기능 통합과 테스트를 조율해 실제 시연 흐름이 자연스럽게 이어지도록 담당했습니다.

## 5. 한 문장 요약

챗봇이 뉴스·ETF 테마·연금계좌·세액공제 질문을 처리하는 도구와 데이터 연동 구조를 설계하고 서비스 통합을 담당했다.

## 개발 작업 경계

- 주 작업 경로는 `backend/app`이며 `backend/app/engine`은 김태형의 규칙 엔진 경계로 분리한다.
- REST 스키마·엔진 I/O 등 공유 계약 변경은 상대 오너와 합의하고 PR에 `계약 변경`을 표시한다.
