# 정인성 — 담당업무 (데이터·서비스 통합 및 고객 UX)

## 1. 담당 역할

### 백엔드·데이터 중심의 서비스 통합 및 고객 UX 개선

고객 데이터와 인증 정보를 설계해 Supabase에 반영하고, 해당 데이터가 프론트 화면과 시연 기능에서 일관되게 사용되도록 통합 및 QA를 담당했다. 홈 화면의 포트폴리오 요약과 챗봇 응답도 개선해 고객이 정보를 더 쉽고 빠르게 이해하도록 사용자 경험을 보완했다.

## 2. 발표자료 카드 문구

고객 목데이터 · 대표 6인 시나리오 · Supabase/Auth · 챗봇·데모 UX·QA

공간이 부족한 경우:

**정인성　고객 데이터·데모 기획**

## 3. 주요 담당 업무

### 고객 데이터 설계

- 1만 명 고객 목(Mock)데이터 구조 구체화
- 고객별 소득·연금 납입액·계좌·자산 정보 구성
- 총급여와 종합소득에 따른 세액공제율 데이터 반영
- 연금저축·IRP 납입액과 세액공제 한도 정보 설계
- 고객 데이터가 화면과 API에서 동일하게 사용되도록 데이터 계약 정리

### 대표 고객 시나리오 구성

- 시연용 대표 고객 6명의 생애주기와 재무 상황 설정
- 투자성향 진단 결과에 맞춘 고객별 시나리오 구성
- 고객별 투자 목적과 판단 근거가 겹치지 않도록 차별화
- 로그인용 고객 계정 및 인증 정보 관리
- 대표 고객의 로그인·투자성향·공개 포트폴리오 데이터 동기화

### ETF 포트폴리오 현실화와 벤치마크 기획

- KODEX·TIGER·ACE·RISE·SOL·HANARO 등 다양한 ETF 활용
- 고객의 나이·투자기간·투자성향에 맞춘 포트폴리오 구성
- 고객별 투자 이유와 포트폴리오 후기 작성
- 과거 수익률과 좋아요 수 등 공개 포트폴리오용 데이터 설계
- 로그인 고객을 제외한 대표 고객의 자산 비중·과거 수익률·좋아요·투자 이유를 비교하는 구조 설계
- 사용자별 공개 지표와 대표 고객 보고서의 데이터 일관성 검증

### 홈 화면 포트폴리오 UX 개선

- 홈 화면 ‘한 줄 요약’을 시황 안내에서 고객 포트폴리오 진단 문장으로 변경
- 고객 자산 중 가장 높은 비중의 자산을 자동으로 판단하도록 구현
- 국내주식과 글로벌주식을 합산해 전체 주식 비중 표시
- 포트폴리오 데이터가 없을 때 사용하는 안내 문구 구현
- 고객 이름에 표시되던 불필요한 데모 표식 제거
- 포트폴리오 요약 로직에 대한 프론트엔드 테스트 추가

### 챗봇 응답 품질 및 비용 개선

- 연금과 무관한 질문에 대한 딱딱한 거절 문구를 친근한 말투로 개선
- 잡담·범위 밖 금융·완전 무관 질문에 결정론적 고정 응답 적용
- 연금계좌 차이·세액공제 계산·맞춤형 포트폴리오 후속 질문 카드 연결
- 오프토픽 답변에서 LLM 내레이션을 실행하지 않도록 해 응답 속도와 비용 효율 개선
- 민감정보·주문·미래수익 예측 등 기존 안전 차단 동작 유지
- 오프토픽 응답과 후속 카드 라우팅에 대한 회귀 테스트 추가

### 서비스 통합 및 시연 QA

- 고객 데이터를 Supabase 및 프로젝트에 반영하고 연결 상태 검증
- Supabase Auth 기반 로그인 고객 계정과 서비스 데이터 연결
- 로그인부터 연금계좌 연동, 투자성향 진단, 홈 화면까지 흐름 점검
- 고객 데이터가 로그인·홈·벤치마크·챗봇에서 동일하게 표시되는지 검증
- 구현 작업의 테스트·PR 승인·`main` 병합까지 수행

## 4. 발표 멘트

저는 백엔드와 데이터 영역을 중심으로 서비스에 사용되는 1만 명의 고객 목데이터와 시연용 대표 고객 6명의 정보를 설계했습니다. 고객별 소득, 연금 납입액, 계좌, 자산, 투자성향을 구체화하고, 각 성향에 맞는 ETF 포트폴리오와 투자 이유, 과거 수익률, 좋아요 데이터를 구성했습니다.

이 데이터를 Supabase와 인증 계정에 반영하고, 로그인부터 연금계좌 연동, 투자성향 진단, 홈 화면과 벤치마크 기능까지 동일한 고객 정보가 일관되게 사용되도록 통합하고 검증했습니다. 또한 홈 화면의 한 줄 요약을 개인 포트폴리오 구성 중심으로 개선하고, 챗봇의 오프토픽 응답을 친근한 결정론 문구로 바꾸면서 불필요한 LLM 호출을 제거해 응답 속도와 비용 효율도 함께 개선했습니다.

## 5. 한 문장 요약

고객 데이터와 대표 시나리오를 설계하고, 해당 데이터가 인증·화면·챗봇·시연 기능에 일관되게 연결되도록 서비스 통합과 고객 UX·QA를 담당했다.

## 개발 작업 경계

- 역할 설명은 수행 기여와 발표 기준이며, 실제 수정 경로는 작업마다 폴더별 `AGENTS.md`·`CLAUDE.md`와 Git 세션 claim으로 확정한다.
- 규칙 엔진 계산식과 백엔드·프론트 공용 계약은 해당 오너와 합의하고 별도 PR로 변경한다.
- 루트 `AGENTS.md`·`CLAUDE.md`는 이재용 전용 잠금 파일이므로 수정하지 않는다.
