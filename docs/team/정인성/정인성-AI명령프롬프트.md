# 정인성 — AI 명령 프롬프트 가이드 (사이드 기능 · 미션·커뮤니티)
> 이 문서를 Claude/Codex에 그대로 복사·붙여넣기 해서 쓴다. 아래 블록을 순서대로 보내면 AI가 대신 한다.

## 0. 사용법 (사람이 읽는 부분)
1. 새 대화에서 §1 온보딩을 한 번 보낸다.
2. AI가 "읽었음"이라고 요약하면 §3에서 지금 할 작업 블록을 보낸다.
3. AI가 "이렇게 만들 계획이야" 하면, 이상 없으면 "진행해" 라고 한다.
4. 만들면 §5 자가검증을 보내 스스로 점검하게 한다.
5. 헷갈리면 §4 문장을 그대로 보낸다. 모르면 "쉽게 설명해줘"라고 해도 된다.
> 팁: 한 번에 다 시키지 말고 한 종류씩. **폴더가 아직 미확정이므로 구현 전에 반드시 이재용에게 폴더 위치를 먼저 확인한다.**

## 1. 온보딩 프롬프트 (대화 시작 시 1회)
```
너는 연금 코파일럿의 사이드 기능(미션·커뮤니티) 작업을 돕는다. 나는 정인성, 사이드 기능 담당이야. 설명은 쉽고 명확하게.
먼저 아래 파일을 읽고 "읽었음"과 함께 ① 커뮤니티·세액공제 기능이 뭔지 ② 아직 확정 안 된 것(폴더 위치 포함)
③ 꼭 지킬 핵심 규칙을 정리해줘. 아직 코드는 만들지 마 — 폴더 위치부터 확인해야 한다.
읽을 파일: 1.CLAUDE.md 2.docs/team/_공통_AI규칙.md(헌장) 3.docs/team/정인성/정인성-담당업무.md 4.docs/10_기획/커뮤니티_세액공제_기능.md
환경: 백엔드는 uv run python(단독 python 금지)/uv run pytest, 프론트는 frontend/에서 npm. 작업 폴더: TODO: 확인 필요(이재용과 먼저 확정).
```

## 2. 고정 규칙 (AI가 작업 때 지킬 것)
```
[고정 규칙]
1. 계산(세액공제액·한도 등)은 규칙 엔진에 맡긴다 — LLM/화면 코드가 직접 계산하지 않는다(헌장 §1).
2. 참고 화면(첨부 이미지)의 수치·상품명·이용자명은 그대로 쓰지 않는다 — 전부 목데이터로 새로 만든다.
3. 포트폴리오 복제·자동 주문·댓글/쪽지 기능은 이번 범위에 없다(기능 명세 §2 "반영하지 않는 요소").
4. 모르는 값은 지어내지 말고 "TODO: 확인 필요" 표시(가짜 값 금지).
5. 한국어 파일은 편집도구/UTF-8로만. main 직접 push 금지(브랜치→PR).
```

## 3. 작업별 명령 프롬프트 (복붙용, 한 종류씩)
### 3-1. 폴더 위치 확정 요청 정리
```
[작업] 커뮤니티·세액공제 기능이 backend/frontend 어디에 들어가야 할지 기존 폴더 구조(아키텍처.md §8)를 기준으로 후보안 2~3개를 정리해줘.
[제약] 실제로 폴더를 만들지는 않는다 — 안만 정리.
[검증] 기존 backend/app/·frontend/src/ 구조와 이름 충돌이 없는지 확인.
[산출물] 후보안 표 → 이재용에게 전달해 확정.
```

### 3-2. 커뮤니티 랭킹 목데이터 설계
```
[작업] mock_public_profiles/mock_public_portfolios 스키마를 기준으로 랭킹 화면에 필요한 조회 쿼리·정렬 기준(수익률순·즐겨찾기순·최신순) 초안을 만들어줘.
[제약] 실제 사용자 데이터·실 수익률과 절대 혼동하지 않는다 — 전부 "목" 라벨 표시.
[검증] 아키텍처.md §5 목 벤치마크 테이블 정의와 일치하는지 확인.
[산출물] 계획(쿼리·정렬 로직) 먼저 → "진행해" 하면 생성.
```

## 4. AI와 일하는 법 (막히면 그대로 보내기)
- 한 번에 하나: `지금은 [이것]만 만들자. 다른 건 건드리지 마.`
- 쉽게 설명: `방금 한 걸 누구나 알아듣게 쉽게 설명해줘.`
- 가짜 값 방지: `이 값 추측이야 출처 있어? 추측이면 TODO로 바꿔줘.`
- 검증: `방금 만든 걸 실제로 실행해서 결과를 보여줘. 빠진 것도 확인해줘.`

## 5. 자가검증 프롬프트 (PR 전)
```
방금 만든 걸 점검하고 표로 보고해줘 (실제로 실행/테스트해서):
1. 폴더 위치를 이재용과 확정했나?  2. 계산 로직을 직접 만들지 않고 엔진에 위임했나?  3. 실/목 데이터 라벨이 명확한가?
4. 한국어 안 깨졌나? 빠진 값 의도된 건가?
아니오가 있으면 고친 뒤 다시 보고해.
```
