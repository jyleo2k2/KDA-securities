## 2. 전체 유저 플로우

```mermaid
flowchart TB
    Start([앱 진입]) -->|실행| S0["S0 로그인/회원가입<br/>데모 세션 · 개인정보 미수집"]
    S0 -->|로그인/가입 완료| S1

    S1{"S1 연금이<br/>처음이신가요?"}
    S1 -->|계좌별 설명 듣기| S1a["계좌 설명 타일<br/>IRP · DC · 연금저축펀드"]
    S1 -->|필요없음| S2
    S1a -->|내 계좌 고르기| S2

    S2["S2 연금 선택<br/>IRP · DC · 연금저축펀드"]
    S2 -->|선택하기| S3

    S3["S3 대시보드(홈)<br/>총자산 · 수익률 · 계좌 비중<br/>동나이대 · 스타일별 비교"]
    S3 -->|상세보기| S3a["계좌 상세<br/>TODO: 화면 미설계"]
    S3a -.->|뒤로| S3

    S3 -->|AI Chat 탭 · 플로팅| S4
    S3 -->|Ranking 탭| S5

    S4["S4 AI 챗봇<br/>추천 질문 칩 + 자유 입력"]
    S4 -->|"칩: DC형 연금이란?"| S4a["엔진 검증 콘텐츠로 답변<br/>(제자리)"]
    S4 -->|"칩: 현재 수익률 확인"| S4b["대시보드 수치 인용 답변<br/>+ 대시보드 이동 버튼"]
    S4 -->|"칩: 은퇴 설계 시뮬레이션"| S4c["시뮬레이션<br/>TODO: 화면/챗봇 내 처리 미확정"]
    S4a -.-> S4
    S4b -.->|이동| S3

    S5["S5 연금 랭킹<br/>섹터별 · 나이대별 · 후기/별점"]
    S5 -->|"Get Started / 따라하기 배너"| S6

    S6["S6 포트폴리오 따라하기<br/>Top 투자자 · 필터 · 팔로우"]
    S6 -->|Follow| S6a["팔로우 등록<br/>(제자리)"]
    S6 -->|AI 진단하기| S6b["성향 진단<br/>TODO: 목적지 미확정 — 챗봇 or 별도 화면"]

    S3 <-.->|하단탭 상호 이동| S4
    S3 <-.->|하단탭| S5
    S4 <-.->|하단탭| S5

    S6 -->|실제 매매 결심| Ext(["금융사 공식 앱에서<br/>이용자가 직접 주문 (서비스 밖)"])
    Ext -.->|재점검 계기: 납입·이직·시장 변동| S3
```

**플로우 원칙**
- S0~S2는 온보딩 일방향, S3~S6은 하단탭 순환 구조.
- 서비스 안에 주문 버튼 없음 — 실행은 항상 서비스 밖(금융사 앱)에서 이용자가 직접.
- 수익률 표시는 전부 과거 실적 + 기준일. 미래 수익 단정 문구 금지.

## 3. 챗봇 추천 질문 칩 — 분기 규칙

| 칩 | 처리 | 이동 |
|---|---|---|
| DC형 연금이란? | 검증 콘텐츠 기반 설명 | 챗봇 내 (제자리) |
| 현재 수익률 확인하기 | 엔진이 계산한 목계좌 수익률 인용 | 제자리 답변 + 대시보드 이동 버튼 |
| 은퇴 설계 시뮬레이션 | 엔진 what-if 실행 | `TODO: 확인 필요` — 챗봇 내 결과 표시 vs 별도 시뮬 화면 |

    end

    H["구조화된 엔진 결과<br/>수치·규칙·가정·기준일·출처"]

    D --> E --> F --> G --> H
