## 3. 핵심 화면 규칙

### S2 홈

- 원그래프: 전체 자산군 비중과 계좌별 합계
- 일일 가이드: 오늘의 시장 일정·위험·점검 항목
- 주간 가이드: 외부 기관 전망과 자산군별 시나리오
- 모든 카드에 출처·기준일·실/목·가정 구분

### S3 연금가이드

| 질문 유형 | 답변 |
|---|---|
| 용어·상품 비교 | 특징·위험·비용·계좌 적격성 |
| 종목·상품 검색 | 뉴스 사실·외부 의견·위험·원문 |
| 성향 기반 전략 | 자산군 전략·근거·가정 시나리오·손실 가능성 |
| 범위 밖 질문 | 한계와 공식 확인 경로 |

### S4·S5 공개 포트폴리오

- 필터: 계좌 조합·연령대·성향·기간
- 표시: 자산군 비중·위험·과거 성과 기준기간
- 비교: 내 구성과의 차이와 점검 질문
- 금지: 실명·정확한 잔액·수익률만의 순위·복사 주문

## 4. 공통 분기

- 출처 또는 기준일이 없으면 정보 카드를 노출하지 않는다.
- 엔진 수치와 LLM 답변이 다르면 답변을 폐기하고 다시 생성한다.
- 성향·계좌 규칙 위반 전략은 차단한다.
- 실제 개인정보 입력이나 주문 요청은 공식 채널 안내로 종료한다.
- 공개 동의를 철회하면 해당 포트폴리오를 즉시 비공개 처리한다.
