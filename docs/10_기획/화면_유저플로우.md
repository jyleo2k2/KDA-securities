# 화면 · 유저 플로우

> 기준: [기획서](./기획서.md) v2.9 · `main` PR #251 · 2026-07-24

## 1. 실제 라우트와 화면

| 라우트 | 화면 | 구현 방식 | 현재 역할 |
|---|---|---|---|
| `#/`, `#/login` | 로그인 게이트 또는 홈 리다이렉트 | React | Supabase 세션 확인 후 로그인·계좌 동의·투자성향 진단을 순서대로 처리 |
| `#/main-home` | 나의 자산 홈 | React | 소유 계좌 총액·자산군 도넛·납입 현황과 챗봇·계산기·전략·User Pick 진입 |
| `#/guide` | 연금가이드 | React + SSE | 검증 지식·엔진·뉴스·ETF 답변, 추천/후속 카드, 대화 저장·삭제, 리밸런싱 알림 |
| `#/planner` | 연금계산기 | React 어댑터 + 정적 iframe | 소유 계좌를 단일/전체로 선택해 적립·수령·CMA 결과 표시 |
| `#/profile-html` | 내 프로필 | React 어댑터 + 정적 iframe | 인증 사용자·저장 투자성향·계좌 데이터 범위와 로그아웃 표시 |
| `#/strategy-explore` | 전략 탐색 | React | 10개 전략 카드 탐색·선택 복원 |
| `#/strategy-detail?strategy=…` | 전략 상세 | React | 선택 전략의 작동 방식·계좌 적용·분류 설명 |
| `#/user-pick-benchmark` | User Pick | React 셸 + 정적 iframe | 대표 포트폴리오 목록·상세 시연, 상세 뒤로가기는 목록으로 복귀 |

`App.tsx`의 `HashRouter`가 위 7개 제품 라우트를 관리한다. 등록되지 않은 경로는 `#/main-home`으로 이동한다.

## 2. 현재 골든패스

~~~mermaid
flowchart LR
    A["로그인"] --> B["계좌 연동 동의<br/>표시 전용"]
    B --> C["투자정보 입력·성향 결과"]
    C --> D["나의 자산 홈"]
    D --> E["연금가이드 챗봇"]
    D --> F["연금계산기"]
    D --> G["전략 탐색 → 상세"]
    D --> H["User Pick 목록 → 상세"]
    E --> F
    E --> D
    F --> D
    G --> D
    H --> D
~~~

- 저장된 투자성향이 유효하면 재로그인 시 설문을 건너뛰고 홈으로 이동한다.
- 허용목록에 든 시연 계정은 평가 결과만 응답하고 투자성향을 DB에 저장하지 않는다.
- 세션 만료는 보호 API 호출 전에 차단하고, 인증 사용자가 바뀌면 사용자별 브라우저 상태를 정리한다.
- 계좌가 없으면 홈 도넛 자리에 연그미 마스코트를 표시한다.

## 3. 화면별 완료·부분 구현

| 영역 | 완료된 동작 | 아직 연결되지 않은 목표 |
|---|---|---|
| 인증·온보딩 | 로그인, 표시용 계좌 동의, 투자성향 평가·저장/복원, 만료 세션 차단 | 실제 금융사/MyData 계좌 연결 |
| 홈 | 소유 계좌 집계, 총액·도넛·기준일, 4개 기능 진입, 계좌 없음 상태 | 출처 기반 일일·주간 정기 가이드 |
| 챗봇 | SSE, 결정론 선응답, 선택적 Claude 재서술, RAG·뉴스·ETF·세금·포트폴리오, 이력·후속 카드 | 원격 배포 환경의 전체 골든패스 재검증 |
| 계산기 | 단일/전체 계좌, 전략 비교, 연차 시계열, 세전·세후 월수령, 현재 ETF CMA | 실제 주문·납입 실행 |
| 전략 | 10종 탐색·상세 설명 | 내 구성 차이 비교와 적용 시뮬레이션 초안 저장 |
| User Pick | 정적 목록·상세와 올바른 뒤로가기 | 로그인 사용자를 제외한 대표고객 5명 동적 조립, 내 구성 차이·적용 초안 |

## 4. 공통 규칙

- 계산·한도 판정·성향 분류는 규칙 엔진 결과만 사용하며 화면과 LLM이 재계산하지 않는다.
- DC형·IRP의 일반 위험자산 70% 한도와 법정 예외, 연금저축의 별도 적격성 규칙을 섞지 않는다.
- 성향 밖 상품을 제안하지 않고, 모든 수치에 출처·기준일 또는 가정을 붙인다.
- 과거 수익률·위험 통계는 미래 수익·손실 예측이나 보장으로 표현하지 않는다.
- 실제 상품 선택·주문은 이용자가 금융회사 공식 채널에서 직접 수행한다.
- User Pick의 시연 데이터 경계는 내부 계약에서 유지하되 사용자 화면에 내부 데이터 종류 라벨을 노출하지 않는다.

## 5. 상태바·모바일 프레임 주의

- 공통 `StatusBar`는 로그인·메인 홈·전략 탐색·전략 상세·`App.tsx` 데스크톱 프리뷰에 적용돼 있다(PR #246·#250).
- 계산기·프로필·벤치마킹 정적 iframe은 React 컴포넌트를 공유하지 않아 별도 구현 경로다.
- PR #250은 `main`에 병합됐지만 Wi-Fi·배터리 아이콘이 사용자 시각 검수를 통과하지 못했다. 고정·공통화 구현은 존재하되 디자인 수용은 미완료다.
