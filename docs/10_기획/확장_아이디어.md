# 확장 아이디어

> [기획서](./기획서.md)의 P0 완료 후 검토하는 백로그다. 확정 기능이 아니다.

## P1 — 학습·점검 경험

- **상세 계좌 진단**: 편중·중복·현금성 자산·계좌 규칙 심화
- **적립·스트레스 시뮬레이션**: 가정 변경과 하락장 비교
- **다음 행동**: 점검 체크리스트·알림·점검일
- **연금 퀴즈·미션**: 규칙·분산·비용 이해 확인
- **교육 피드**: 검증된 콘텐츠와 개인 학습 진도

## P1 — 공개 포트폴리오 확장

- 팔로우·즐겨찾기
- 내 포트폴리오와의 비교 리포트 저장
- 점검 경험과 질문 공유
- 신고·차단·검수된 활동 피드

후기·별점은 상품 수익률이 아니라 정보 유용성과 학습 경험만 평가한다.

## P2 — 실서비스 확장

- 실계좌·마이데이터 연동
- 실제 이용자 포트폴리오 게시
- 등록업무 범위의 개인화 상품 자문
- 금융회사 공식 주문 연결
- 자동 리밸런싱·투자일임

## 채택 기준

아이디어는 다음 조건을 모두 만족할 때 기획서로 이동한다.

1. P0 사용자 문제를 더 잘 해결한다.
2. 필요한 데이터와 운영 주체가 명확하다.
3. 규제·개인정보·콘텐츠 권리를 검토했다.
4. 테스트 가능한 완료 기준이 있다.
5. 현재 일정과 팀 역량으로 구현 가능하다.

## 보류 중

- 연령대 비교의 모집단과 출처
- 방치 이유 진단 문항
- 직업·소득과 투자자산의 집중위험 분석
- 성향별 교육용 자산군 기준
- 후기·별점과 게시물 운영정책

공통 가드레일은 [컴플라이언스](../40_규제/컴플라이언스.md)를 따른다.
