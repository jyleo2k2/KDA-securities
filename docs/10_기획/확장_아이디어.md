# 보다 가까워지는 연금 - 서비스 개요

> 상태: 아이디어 상세 정리. 프로젝트의 최신 기획 SSOT는 [연금계좌_운용가이드_프로젝트_기획서.md](./기획서.md)다.
>
> 원칙: 교육·의사결정 지원형 서비스이며, AI는 근거를 설명한다. 실제 상품 선택과 실행은 이용자가 직접 판단한다.

## 1. 서비스 한 줄 정의

연금을 어렵고 먼 과제가 아니라, **내 계좌를 이해하고 오늘의 작은 점검 행동을 선택하는 일상**으로 바꾸는 연금계좌 운용 가이드다.

대상은 DC형 퇴직연금·IRP·연금저축계좌 중 하나 이상을 보유했지만, 계좌를 방치했거나 무엇을 어떻게 점검해야 할지 모르는 이용자다.

## 2. 핵심 경험

1. 방치된 계좌와 문제를 발견한다.
2. 현재 상태와 판단 근거를 쉬운 언어로 이해한다.
3. 위험·비용·계좌 규칙을 고려한 교육용 선택 기준을 배운다.
4. 다음에 실제 앱에서 확인하거나 실행할 행동을 고른다.
5. 커뮤니티·퀴즈·미션으로 점검 습관을 이어 간다.

## 3. 기능 구성

### 3.1 연금 장려

비활성 계좌 이용자가 연금 점검을 시작하도록 돕는 진입 기능이다.

- 동나이대의 상품 보유 현황이 아니라, 점검·납입·분산 같은 준비 행동을 비교 기준으로 제공한다.
- `그때 넣었더라면` 가상 체험으로 과거의 적립 가정을 보여주되, 후회 유도가 아니라 오늘부터의 적립 행동으로 연결한다.
- 방치 이유를 진단한다. 예: 몰라서 미룸, 하락이 불안함, 현금이 편함, 상품 선택이 어려움.
- 방치 이유에 따라 다음 행동과 교육용 상품 선택 기준을 다르게 제시한다.

### 3.2 계좌 진단과 교육형 설명

계좌의 현재 상태를 보여주는 데서 끝나지 않고, 왜 확인이 필요한지와 무엇을 배워야 하는지를 함께 설명한다.

| 구분 | 이용자에게 보여줄 내용 |
|---|---|
| 현재 상태 | 잔액, 납입액, 수익률, 상품별 비중, 현금성 자산, 위험자산 비중, 총비용 |
| 문제 진단 | 장기 미운용, 현금 과다, 특정 자산 쏠림, 상품 중복, 목표 비중 이탈 |
| 판단 근거 | 문제 이유, 적용 규칙, 기준일, 데이터 출처 |
| 교육용 대안 | 성향별 자산군 비중 예시와 각 자산군의 역할 |
| 위험 설명 | 예상수익 대신 손실 가능 범위, 스트레스 상황, 원금보장·예금자보호 여부 |
| 비용·거래 조건 | 총보수, 매매비용, 환매기간, 만기, 환율·금리·신용위험 |

#### 하락장 멘탈 관리

- 스트레스 진단으로 이용자가 손실을 어느 정도까지 감당하기 어려운지 점검한다.
- 하락 원인을 시장·금리·환율·신용·섹터 등 이해 가능한 단위로 설명한다.
- 즉시 매매를 유도하지 않고, 미리 정한 점검 행동과 성향을 다시 확인하게 한다.

#### 직업 연계 리밸런싱

- 이용자의 직업·소득과 연금 자산이 같은 산업에 동시에 노출됐는지 확인한다.
- 특정 산업 쏠림을 줄이는 분산 원칙을 설명한다.
- 리밸런싱은 성향, 계좌별 규칙, 집중위험을 근거로 교육용 예시를 제공한다.

### 3.3 전후 비교와 다음 행동

- 현재 구성을 유지했을 때와 비중을 변경한 교육용 시나리오를 장기 적립·하락장 관점에서 비교한다.
- 실제 앱에서 확인하거나 변경해야 할 다음 단계를 체크리스트로 안내한다.
- 화면마다 목데이터 여부, 교육용 예시, 미래 성과 비보장, 실제 주문 미지원 여부를 표시한다.
- 설명형 Q&A는 답변마다 적용 수치·규칙·공식 출처를 함께 표시한다.

## 4. 연금 커뮤니티

연금 커뮤니티는 비슷한 은퇴 시기·성향·목표를 가진 이용자의 랭킹·포트폴리오·질문·점검 경험을 확인하는 공간이다. (2026-07-14 방향 전환: 자문·정보 제공형 — Figma 확정 화면 기준)

- **연금 랭킹**: 섹터별·나이대별 수익률 랭킹과 상위 투자자의 포트폴리오 구성을 확인한다. 수익률은 과거 실적만 표시하고 기준일을 붙인다.
- **연금 포트폴리오 따라하기**: 상위 투자자의 자산배분(예: 미국 주식 45%·채권 30%)을 참고해 나만의 전략을 세운다. 과거 수익률·위험 지수를 함께 표시하며, **실제 주문은 이용자가 금융사 앱에서 직접** 한다.
- **팔로우**: 성향이 맞는 투자자를 팔로우해 포트폴리오 변화를 참고한다.

### 후기와 별점

- 후기는 초보자 친화도, 정보 유용성, 활동 만족도, 운영 신뢰도 등 경험 정보 중심으로 남긴다.
- 별점은 상품 수익률 평가가 아니라 크루 활동과 교육 경험의 만족도를 평가한다.
- 수익 보장 표현과 미래 수익률 단정은 금지한다. 손익 데이터는 과거 실적으로만 표시한다.
- 핵심 질문은 `이 경험이 나에게 잘 맞는가?`다.

## 5. 연금 퀴즈와 미션

### 퀴즈

- 위험자산 한도와 계좌별 규칙
- 자산군의 역할과 분산
- 하락장 행동 원칙
- 수수료·비용과 점검 주기

정답 경쟁보다, 이용자가 다음 행동의 이유를 이해했는지 확인하는 교육 장치로 사용한다.

### 미션

- 내 계좌 열기
- 상품별 비중 구분하기
- 현금성 자산과 위험자산 비중 확인하기
- 총비용과 거래 조건 확인하기
- 다음 점검일 정하기

진행 기록은 수익률 경쟁이 아니라 **이해 → 점검 → 실행**의 누적으로 보여준다.

## 6. 운영 가드레일

- AI는 계산하거나 주문하지 않는다. 규칙 기반 엔진의 결과를 설명하고 Q&A를 제공한다.
- 실제 상품 선택과 실행은 이용자의 직접 판단과 승인으로만 이뤄진다.
- DC형·IRP의 위험자산 한도·예외 규칙과 연금저축의 상품 적격성 규칙을 계좌별로 분리한다.
- 성향 밖의 상품 제안은 차단하며, 모든 수치에는 출처 또는 가정 칩을 표시한다.
- 시장·제도·상품 정보는 공식 공개 데이터로, 이용자 계좌는 시나리오 목데이터로 명확히 구분한다.
