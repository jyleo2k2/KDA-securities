# 연금계좌 운용 가이드 — 프로젝트 기획서

> 버전 v2.4 · 2026-07-14 · MVP 구현 전
>
> 대상: DC형 퇴직연금 · 개인형 IRP · 연금저축계좌

## 1. 제품 정의

**세 연금계좌의 통합 포트폴리오를 보여주고, 시장·상품 정보를 근거와 함께 설명하며, 공개 포트폴리오 벤치마킹으로 이용자의 연금 투자 판단을 돕는 AI 연금가이드.**

- **문제**: 이용자는 계좌별 규칙, 전체 자산구성, 시장·상품 정보를 한 흐름에서 이해하기 어렵다.
- **타깃**: 연금계좌를 보유했지만 전체 구성과 운용 판단 기준이 부족한 직장인.
- **차별화**: 통합 포트폴리오 × 출처 기반 가이드 × 설명 가능한 챗봇 × 익명 벤치마킹.
- **원칙**: AI는 제안과 설명만 하며 실제 선택·주문은 이용자가 공식 채널에서 직접 수행한다.

## 2. MVP 범위

### 골든패스

~~~text
목계좌 선택
→ 홈에서 통합 포트폴리오와 일일·주간 가이드 확인
→ 연금가이드에 상품·전략 질문
→ 공개 포트폴리오와 내 구성 비교
→ 이용자가 점검할 항목 결정
~~~

### 핵심 기능 P0

| 기능 | 사용자 경험 | MVP 출력 |
|---|---|---|
| **내 연금 포트폴리오 홈** | 세 계좌의 전체 구성과 시장 영향을 파악 | 원그래프, 일일 점검, 출처 기반 주간 이상 매크로 가이드 |
| **연금가이드 챗봇** | 용어·상품·종목·전략을 질문 | 상품 비교, 뉴스·외부 리서치 요약, 성향 기반 자산군 전략 |
| **공개 포트폴리오** | 유사 이용자 구성을 참고 | 익명 목록·상세, 내 포트폴리오와 차이 보기 |

#### 1) 내 연금 포트폴리오 홈

- DC형·IRP·연금저축을 합산한 자산군 원그래프와 계좌별 비중을 표시한다.
- 일일 가이드는 당일 시장 일정과 포트폴리오 점검 항목을 짧게 제공한다.
- 주간 이상 가이드는 공식 지표와 기관 전망을 사실·전망·해석으로 구분한다.
- 모든 정보에 출처·기준일·업데이트 시각을 표시한다.

#### 2) 연금가이드 챗봇

- 연금상품의 용어·특징·위험·비용·계좌 적격성을 설명하고 비교한다.
- 검색 종목·상품의 뉴스 사실과 외부 애널리스트 의견을 출처별로 구분한다.
- 목투자성향·기간·계좌 규칙에 맞는 자산군 전략을 설명한다.
- 사용자 요청상 ‘예상수익률’은 **미래 예측값이 아닌 승인된 가정의 시나리오 범위**로만 표시하며 손실 가능성을 함께 제시한다.

#### 3) 공개 포트폴리오

- 계좌 조합·연령대·성향·기간으로 익명 포트폴리오를 탐색한다.
- 비중·위험·과거 기간수익률을 동일 기준으로 비교한다.
- 기본 CTA는 ‘따라하기’가 아니라 **내 포트폴리오와 차이 보기**다.
- MVP는 공개용 목데이터를 사용한다. 전용 ‘벤치마크’ 탭은 우선안이며 최종 위치는 미확정이다.

### 공통 기반

- 목계좌·목성향·공개용 목포트폴리오
- 계좌별 규칙, 통합 집계, 성향·한도 가드레일
- 실데이터·목데이터·가정값 구분
- 출처·기준일·권리상태와 LLM 답변 검증
- 익명화·금액 마스킹·감사 로그

### 부가기능

- **P1**: 상세 계좌 진단, 적립·스트레스 시뮬레이션, 체크리스트·알림, 퀴즈·미션, 팔로우·즐겨찾기
- **P2**: 실계좌 연동, 실제 이용자 게시, 등록업무 범위의 개인화 자문, 주문 연결, 자동운용

부가기능의 후보와 보류 사유는 [확장 아이디어](./확장_아이디어.md)에서 관리한다.

## 3. 사용자 경험

권장 하단 탭은 **홈 · 연금가이드 · 벤치마크 · 프로필**이다.

- 홈은 전체 상태와 정기 가이드의 출발점이다.
- 챗봇 답변은 사실·외부 의견·서비스 해석을 구분한다.
- 벤치마크는 수익률 순위보다 구성·위험 차이를 먼저 보여준다.
- 주요 CTA는 주문이 아니라 차이 확인과 공식 정보 확인이다.

화면과 분기는 [화면·유저 플로우](./화면_유저플로우.md)를 따른다.

## 4. 계산·데이터·AI 원칙

- 계산·한도 판정·성향 분류·전략 선택은 규칙 엔진이 담당한다.
- LLM은 엔진 결과와 검증된 외부 정보를 설명하며 새 숫자·목표가·매매의견을 만들지 않는다.
- 시장·제도·상품은 공식 실데이터, 사용자 계좌와 공개 포트폴리오는 MVP 목데이터를 사용한다.
- 뉴스·리포트는 사실과 의견을 분리하고 발행기관·발행일·원문·이용권 상태를 보존한다.
- DC형·IRP 규칙과 연금저축 적격성 규칙을 분리한다.

기술 계약은 [아키텍처](../30_스펙/아키텍처.md), 수익률 가정은 [수익률 가정 모델](../30_스펙/수익률_가정_모델.md)에서 관리한다.

## 5. 이용자 보호 경계

MVP에서 제공하지 않는다.

- AI 자체 매수·매도·목표가와 확정적 시장 전망
- 수익 보장 또는 단일 미래 예상수익률
- 성향·계좌 규칙을 벗어난 전략
- 실제 계좌·개인정보 수집, 주문, 자동 리밸런싱
- 뉴스·리포트 원문의 무단 복제
- 실명·정확한 잔액 공개와 원클릭 복사 주문

실서비스 전 투자자문·권유, 적합성·설명의무, 개인정보, 콘텐츠 권리와 게시물 운영을 다시 검토한다. 상세 기준은 [컴플라이언스](../40_규제/컴플라이언스.md)를 따른다.

## 6. MVP 완료 기준

- [ ] 세 계좌 합계와 통합 원그래프가 일치한다.
- [ ] 일일·주간 가이드에 출처·기준일과 사실/전망 구분이 있다.
- [ ] 챗봇 수치와 의견이 엔진 또는 원 출처와 일치한다.
- [ ] 전략이 성향·계좌 규칙을 준수하고 손실 가능성을 함께 표시한다.
- [ ] 공개 포트폴리오에 식별정보·정확한 잔액·복사 주문 CTA가 없다.
- [ ] 이용자가 자신의 구성, 정보의 근거, 벤치마크와의 차이를 설명할 수 있다.

## 7. 구현 순서와 미확정

1. 목데이터와 규칙·출처 계약
2. 홈 원그래프와 일일·주간 가이드
3. 챗봇 질문 유형 3종
4. 공개 포트폴리오 목록·상세·차이 보기
5. 공통 검증과 사용자 과업 테스트

확정이 필요한 항목:

- 벤치마크의 최종 메뉴 위치
- 일일·주간 가이드의 기관·기간·갱신주기
- 뉴스·애널리스트 리포트 이용권
- 성향 전략과 가정 시나리오 기준
- 공개 필드·성과표시·신고 정책
- 팀 역할과 세부 기술 스택
