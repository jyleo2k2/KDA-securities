# 화면 표시 데이터 계약

> 범위: 투자전략 상세와 연금계산기 세액공제 화면이 순수 엔진에서 받는 표시용 데이터.
> 이 계약은 계산 가정·후보 선정·자산배분을 바꾸지 않는다.

## 전략 표시 메타

| strategy_id | display_name | risk_badge | character_key |
| --- | --- | --- | --- |
| `capital_preservation_core` | 안정 중심 전략 | 안정형 | `capital_preservation_core` |
| `defensive_diversified_core` | 방어 분산 전략 | 안정추구형 | `defensive_diversified_core` |
| `balanced_core_satellite` | 균형 코어·위성 전략 | 위험중립형 | `balanced_core_satellite` |
| `growth_core_satellite` | 성장 코어·위성 전략 | 적극투자형 | `growth_core_satellite` |
| `barbell_growth_tactical` | 테마 집중 전략 | 공격투자형 | `barbell_growth_tactical` |

`summary`는 각 전략의 구성 방식을 한 줄로 설명한다. 미래 수익률 예측·보장 표현은 사용하지 않는다. `character_key`는 프론트 에셋 선택 키이며, 이번 계약에는 이미지 파일을 포함하지 않는다.

`PensionCalculatorStrategy.presentation`과 `EducationalPortfolioEvaluation.strategy_presentation`은 같은 `StrategyPresentation` 객체를 반환한다.

## 자산군 표시 집계

교육용 ETF 후보의 기존 `classification.asset_class`와 `classification.region`을 화면의 다섯 칸으로 투영한다. 이는 후보 선정이나 원본 ETF 분류를 변경하지 않는 표시 전용 규칙이다.

| 표시 칸 | 후보 분류 규칙 |
| --- | --- |
| 국내 주식형 | `equity` + `south_korea` |
| 해외 주식형 | `equity` + 한국 이외의 확인된 지역 |
| 채권형 | `fixed_income` |
| 대체 | `commodity`, `real_estate`, `alternative` |
| 현금성 | `cash_equivalent`; `DEPOSIT`은 같은 표시 칸으로 합산 |

응답은 `asset_class_allocation`에 위 다섯 칸을 항상 이 순서로 포함한다. 각 값은 후보의 `target_percent` 합계다. 후보별 비중의 반올림으로 생기는 ±0.0001%p 잔차는 가장 큰 표시 칸에 보정한다. 동률이면 표 순서를 따른다. 이 보정은 화면 집계에만 적용하며 후보 비중을 바꾸지 않는다.

`multi_asset`, `currency`, 지역이 없는 `equity`, 또는 미확정 분류는 임의 배정하지 않는다. 해당 후보 코드가 `asset_class_display_unclassified:{isu_code}` 경고로 반환되며, 이 경우 화면 합계 100%를 보정하지 않는다. `ELIGIBLE_TDF`와 `DEFAULT_OPTION`은 화면 자산군이 아니라 상품유형이며 교육용 ETF 후보에 배정하지 않는다.

## 세액공제 잔여한도

`PensionTaxCreditEvaluation`은 기존 필드를 유지하고 아래 표시용 필드를 추가한다.

| 필드 | 계산 |
| --- | --- |
| `remaining_eligible_contribution_krw` | `max(900만원 - regular_eligible_contribution_krw, 0)` |
| `additional_tax_credit_krw` | 소득구간 확정 시 남은 금액 × 기존 표시율(16.5% 또는 13.2%); 미확정이면 `null` |
| `limit_usage_percent` | `regular_eligible_contribution_krw / 900만원 × 100`, 소수 둘째 자리 반올림 |

세 필드는 연금저축·IRP·DC 개인 추가납입의 **정규 합산 900만원 한도** 기준이다. 연금저축 단독 600만원 한도는 기존 `pension_savings_eligible_contribution_krw`으로 확인한다. ISA 만기자금 전환으로 생기는 추가한도는 정규 납입 여력·소진율에 섞지 않는다.

`additional_tax_credit_krw`는 기존 UI 표시율을 재사용한 지방소득세 포함 추정 절감효과다. 실제 공제·환급은 결정세액과 개인 과세상황에 따라 달라질 수 있다.
