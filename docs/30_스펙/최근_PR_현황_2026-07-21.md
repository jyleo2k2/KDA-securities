## 기능 묶음별 현재 상태

### 로그인과 사용자 전환

- Supabase 설정 환경에서는 미로그인 사용자의 해시 경로 우회를 세션 게이트가 막는다.
- 로그인 후 사용자 컨텍스트와 시나리오 상세를 조회해 홈·프로필·챗봇을 같은 사용자 기준으로 표시한다.
- A 사용자 요청이 진행 중일 때 B 사용자로 전환해도 A 데이터가 B 화면에 나타나지 않도록 요청 세대를 검증한다.
- 로그아웃은 화면 상태와 사용자별 로컬 저장값만 초기화한다. 서버 대화는 세션 목록의 명시적 삭제 버튼으로만 삭제한다.
- 실제 금융사 계좌 연결과 PR #115의 계좌 동의 화면은 아직 `main`에 없다.

### 챗봇 표시 품질

### 시장 뉴스 수집·표시

- 시의성 질문은 NAVER 실시간 메타데이터를 우선 조회하고 실패하면 저장 뉴스로 폴백한다. 종목·미수집 국가·연금 제도 뉴스는 지원 범위를 알린 뒤 한국·미국 증시 뉴스로 대체한다.
- PR #122의 기본 수집은 기존 최근 24시간·첫 페이지 동작을 유지한다. 과거 수집은 timezone-aware `[window_start, now)`를 최대 24시간, 최대 10페이지로 제한한다.
- 페이지는 `start=1, 1+display, ...`로 이동하고 구간 시작 이전 기사·짧은 응답·1,000건 한계·전체 건수 도달 시 중단한다. 실행 이력에는 `max_pages`와 선택적 `window_end`를 남긴다.
- GitHub Actions의 `17 3 * * *` cron은 03:17 UTC, 한국시간 12:17 실행이다. 워크플로 입력의 `timezone: Asia/Seoul`은 cron 자체의 시간대를 바꾸지 않는다.
