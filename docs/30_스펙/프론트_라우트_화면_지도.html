헷갈리기 쉬운 구조

이름은 비슷한데 다른 화면들

홈은 하나

기존 HomePage와 #/home은 삭제했어요. 로그인 후 홈은 MainHomeScreen(#/main-home) 하나이며 소유자 계좌 데이터를 사용해요.

프로필도 하나

기존 ProfilePage와 #/profile은 삭제했어요. 허브 헤더는 실제 사용자 데이터를 주입하는 ProfileHtmlPage(#/profile-html)를 열어요.

정적 임베드 4개

planner와 profile-html은 iframe이지만 React 래퍼가 실제 사용자·엔진 데이터를 주입해요. user-pick-benchmark는 내 계좌와 분리된 비교 시연 전용이에요.

공통 모바일 셸

모든 사용자 화면은 데스크톱에서 390×844 베젤 프레임과 상태바 아래의 시작 여백을 사용해요. 실제 휴대폰 폭에서는 베젤만 제거하고 같은 화면 흐름을 유지해요.
