# 거시지표 기반 계획가정 검토 계약

> 상태: BOK ECOS·KOSIS·FRED 실데이터 수집·품질 게이트·과거 유사국면 API 구현
> 정책 버전: `macro-evidence-2026-07-20.1`
> 금지: 최근 금리·물가를 ETF 미래수익률, 목표비중 또는 리밸런싱 신호로 직접 사용

## 목적

거시지표는 승인된 장기 계획가정을 자동으로 바꾸는 입력이 아니다. 연례 계획가정 검토 시
현재 관측 환경과 기존 가정의 차이를 설명하고, 데이터 누락·지연을 탐지하는 근거 계층이다.
계산 엔진의 버킷 수익률, ETF 계획수익률, 글라이드패스와 계좌별 위험자산 한도는 변경하지
않는다.

## 수집 대상

| 출처 | 지표 | 공식 코드 | 용도 |
|---|---|---|---|
| 한국은행 ECOS | 한국은행 기준금리 | `722Y001` / `0101000` / 일 | 국내 금리 환경 설명 |
| 한국은행 ECOS | 소비자물가지수 총지수 | `901Y009` / `0` / 월 | 과거 전년동월비 산출·물가 가정 검토 |
| KOSIS | 대한민국 65세 기대수명(남·여) | `101` / `DT_2OEHG072` / `T001` | 은퇴기간·장수위험 설명 |
| FRED | 미국 연방기금 실효금리 | `FEDFUNDS` | 글로벌 금리 환경 설명 |
| FRED | 미국 소비자물가지수 전년동월비 | `CPIAUCSL`, `units=pc1` | 글로벌 물가 환경 설명 |
| FRED | 미국 10년 국채금리 | `DGS10` | 글로벌 장기금리 설명 |
| FRED | 미국 10년 기대인플레이션 | `T10YIE` | 시장 관측 기대인플레이션 설명 |

KOSIS 장래인구추계 표는 사용하지 않는다. 현재 구현은 과거 65세 기대수명 관측만 가져오며,
개별 사용자의 사망연령이나 연금수령기간을 예측하지 않는다.

## 데이터 계약

수집기는 각 공식 응답의 원문, 비밀키를 제외한 요청 파라미터, 기준일과 SHA-256을 보존한다.
정규화 결과는 `Decimal` 문자열로 저장하며 한국 소비자물가 전년동월비는 아래 공식으로만
파생한다.

```text
(당월 소비자물가지수 / 12개월 전 소비자물가지수 - 1) × 100
```

품질 게이트는 일별 7일, 월별 2개월, 연별 3년의 최대 관측 지연을 검사한다. 필수 8개
지표 중 하나라도 누락 또는 지연되거나 한국 소비자물가 전년동월비를 산출할 수 없으면
보고서 상태는 `incomplete`다. 이는 수집 파이프라인 품질 기준이며 투자판단 임계값이 아니다.

## 알고리즘 연결 경계

허용:

- 연례 계획가정 검토 자료
- 챗봇의 금리·물가·장수위험 설명과 출처 칩
- 기존 고정 물가가정의 재승인 필요성 검토

금지:

- 최신 기준금리나 CPI를 장기 CMA에 자동 대입
- 금리·물가 변화만으로 ETF 목표비중 변경
- 거시지표를 단기 매수·매도 또는 리밸런싱 트리거로 사용
- FRED 기대인플레이션을 확정 미래물가로 표시
- KOSIS 기대수명으로 개인의 사망연령을 추정

수치 변경이 필요하면 김태형 엔진 오너가 별도 정책 버전과 120개 포트폴리오 결과 비교를
승인해야 한다.

## FastAPI·챗봇 연결 정책 (2026-07-20 승인)

- 수집 정책 `macro-evidence-2026-07-20.1`은 유지하고, 계획가정 정책은
  `2026-07-20.2`로 분리한다.
- `GET /macro/evidence`는 최신 보고서에서 공식 관측값·기준일·출처 URL·알고리즘 사용
  경계만 반환한다. 원본 경로, 요청 파라미터, 해시와 API 키는 반환하지 않는다.
- 챗봇은 같은 읽기 모델로 공식 통계 출처 칩을 만든다. 보고서가 없거나 손상되면 수치를
  생성하지 않고 가용성 안내만 반환한다.
- 기본 물가가정 `2.0%`는 한국은행 물가안정목표 근거를 연결하되 최근 CPI로 자동 변경하지
  않는다. 계획수익률·ETF 비중·리밸런싱 규칙의 숫자는 바꾸지 않는다.

## 과거 유사국면 계약 (2026-07-20 엔진 오너 승인)

- 데이터셋 정책은 `macro-regime-dataset-2026-07-20.1`, 유사도 엔진 정책은
  `macro-analog-regime-2026-07-20.1`로 분리한다.
- 월별 6개 지표만 사용한다: 한국 기준금리·한국 CPI 전년동월비·미국 연방기금금리·미국
  CPI 전년동월비·미국 10년 국채금리·미국 10년 기대인플레이션.
- 한국 기준금리는 월말 유효값을 다음 변경 전까지 이월한다. CPI와 연방기금금리는 월별
  관측값, 미국 10년물과 기대인플레이션은 일별 관측의 월평균을 사용한다.
- 각 시점까지의 자료만 사용하는 36개월 이상 확장창 z-score로 표준화하고, 6개 지표
  동일가중 RMS 거리를 사용한다. 현재와 12개월 미만인 시점은 제외하고 서로 12개월 이상
  떨어진 과거 국면 최대 5개를 반환한다.
- `GET /macro/analog-regimes`는 정규화 방식·현재 월·현재 값과 z-score·유사 과거 월과 거리,
  지표별 공식 출처만 반환한다. 원본 경로·요청 파라미터·SHA-256·API 키는 반환하지 않는다.
- 결과는 과거 환경 설명 근거이며 미래수익률 예측, 계획수익률 입력, 목표비중 변경 또는
  리밸런싱 신호가 아니다.
- `POST /macro/analog-regimes/etf-outcomes`는 선택 ETF의 과거 유사국면 이후 3·6·12개월
  총수익률·최대낙폭만 결합한다. 한투 수정주가와 KIND 현금분배를 모두 갖춘 총수익 이력만
  사용하며, 결측 경계는 보간하지 않는다.
- ETF 상장 또는 공식 이력 백필 이전인 기간은 `outcome_precedes_history_coverage`, 현재
  이력 종료 뒤 기간은 `outcome_exceeds_history_coverage`으로 명시한다. 두 경우 모두
  성과 수치·목표비중·리밸런싱 신호를 생성하지 않는다.

## 실행·산출물

```powershell
uv run python -m backend.app.ingestion.macro --env-file .env
```

- 원본: `data/raw/macro/{기준일}/{출처}/`
- 최신 보고서: `data/cache/macro/macro_evidence_latest.json`
- 실제 키는 루트 `.env`에서만 읽으며 로그·오류·manifest에 저장하지 않는다.

공식 명세:

- 한국은행 ECOS Open API: <https://ecos.bok.or.kr/api/>
- KOSIS 통계자료 API: <https://kosis.kr/openapi/devGuide/devGuide_0201List.do>
- FRED observations API: <https://fred.stlouisfed.org/docs/api/fred/series_observations.html>
