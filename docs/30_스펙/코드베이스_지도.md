# 코드베이스 지도 — 세션 시작 캐시

> **목적**: 새 세션이 매번 소스 전체(약 5만 줄, 100+ 파일)를 다시 읽지 않고 이 문서로 구조·데이터흐름·핵심 알고리즘을 먼저 파악하기 위한 캐시 문서다.
> **역할 분리**: "왜 이렇게 결정했는지"는 [아키텍처.md](./아키텍처.md)(계약·경계), "지금 뭘 하고 있는지"는 [README.md](../../README.md)·[CLAUDE.md](../../CLAUDE.md) 현재 상태, "실제 파일에 뭐가 있는지·어떻게 동작하는지"는 이 문서.
> **갱신 시점**: 새 모듈 추가, 파이프라인 구조 변경, 핵심 알고리즘 교체 등 구조적 변경이 있을 때만 같은 PR에서 갱신한다. 버그 수정·소규모 리팩터링은 갱신 불필요.
> **신뢰 한도**: 이 문서는 스냅샷이다. 파일 경로·함수명이 실제로 존재하는지는 인용 전에 확인한다("메모리가 X라 한다"는 "X가 지금도 있다"와 다르다).
> 최종 갱신: 2026-07-22 (금융투자협회 ETF TER 원본 보존·비용 캐시 결합 반영)

## 0. 전체 구조

```
[수집기 backend/app/ingestion/] → 파일캐시 data/raw,cache/ → [리포트 빌더 backend/app/*_report.py] → Supabase 적재(*_database.py)
                                                                                                        ↓
[React PWA frontend/] ←SSE← [FastAPI backend/app/api/] → [chat/ 오케스트레이션] → [engine/ 순수 규칙엔진]
                                     ↓                          ↓                        ↑
                              [retrieval/ RAG]           narrator.py(Claude 서술만)
```

4계층(엔진·챗봇·RAG·수집)은 각각 별도 세션 하네스가 있다(`backend/app/engine/CLAUDE.md`, `backend/app/chat/CLAUDE.md`, `backend/app/retrieval/CLAUDE.md`, `frontend/CLAUDE.md`, `supabase/CLAUDE.md`) — 소유·금지 경계·검증 명령의 SSOT는 그 파일들이다. 이 문서는 소유권이 아니라 **구현 내용**을 다룬다.

### `educational_portfolio.py` 파이프라인 (성향 입력 → 최종 포트폴리오)
1. `calculate_target_allocation` — `PROFILE_POLICY`(성향별 base_risk/min/max/tactical/cash) → 나이·은퇴연령 보정 → 계좌 한도 캡(DC·IRP 70%, 연금저축 90%) → `_fit_loss_tolerance`(이분탐색으로 손실감내율에 맞춰 리스크 축소) → 5슬리브(core_equity/real_assets/tactical/fixed_income/cash) 배분.
2. `select_educational_candidates` — `_score_candidates`(비용20%·유동성25%·규모20%·NAV15%·추적오차15%·이력5% 백분위 합산, **과거수익률은 랭킹에 미사용**) → 슬리브별 후보 선정 시 상관계수(`calculate_return_correlation`, 60일 미만 데이터는 None) 0.75 초과·동일권역 페널티. PR #83: 유니버스 단위 품질점수 캐시 + 정렬·이진탐색 백분위로 가속(`Decimal` 유지, 120개 결과 동등 검증).
3. `calculate_portfolio_risk` — 후보 가중 일별수익률로 변동성·다운사이드·MDD·VaR95 계산(공통관측 60일 미만이면 `insufficient_common_history` 상태). PR #83: 위험 통계 내부 계산을 numpy로 가속(결과 동등 검증). `STRESS_POLICY`(equity_drawdown/rate_inflation_shock/stagflation) 3종 스트레스 손실.
4. `calculate_portfolio_planning_return` — 상품 분류→`_cma_mapping`(J.P.Morgan 2026 CMA 앵커, `CMA_ASSUMPTIONS_PERCENT`) → `_uncertainty_discount`(전략별 0.10~1.00) → `calculate_etf_planning_return` 재사용 → 목표비중 가중평균. `annual_review_required=True`(30년 고정 아님).
5. `build_educational_portfolio` — 위 결과 조립 + `calculate_rebalancing_guidance`(목표비중 이탈 5%p 기준, 매도지시 미생성·납입금 우선 배분).
