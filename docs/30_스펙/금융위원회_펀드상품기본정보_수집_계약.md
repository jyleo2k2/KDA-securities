# 금융위원회 펀드상품기본정보 수집 계약

## 목적

금융투자협회 펀드표준코드 기반의 펀드상품 기본정보를 금융위원회 공공데이터 API에서 수집하고, KRX 현재 상장·관측충분 ETF 목록에 공식 펀드유형과 상품분류코드를 보조 근거로 연결한다.

## 공식 API

- 서비스: 금융위원회_펀드상품기본정보
- 오퍼레이션: `getStandardCodeInfo`
- Endpoint: `https://apis.data.go.kr/1160100/service/GetFundProductInfoService/getStandardCodeInfo`
- 필터: `likeFndNm=상장지수투자신탁`
- 인증: `.env`의 `FSC_FUND_PRODUCT_API_KEY`
- 공식 페이지: <https://www.data.go.kr/tcs/dss/selectApiDataDetailView.do?publicDataPk=15094792>

키는 요청 시에만 사용하고 로그, 오류, 원본, 캐시, 매니페스트에 기록하지 않는다.

## 원본 필드

| 필드 | 의미 |
|---|---|
| `basDt` | 기준일 |
| `srtnCd` | 펀드 단축코드 |
| `fndNm` | 펀드명 |
| `ctg` | 범주 |
| `setpDt` | 설정일 |
| `fndTp` | 펀드유형 |
| `prdClsfCd` | 상품분류코드 |
| `asoStdCd` | 펀드표준코드 |

## 저장 구조

```text
data/raw/fsc/fund_product_basic/
  YYYY-MM-DD/page_NNNN.json
  manifests/fund_product_basic_YYYY-MM-DD.json
data/cache/fsc/
  fund_product_basic_YYYY-MM-DD.json
  krx_etf_fund_join_YYYY-MM-DD.json
```

원본 응답 bytes를 페이지별로 보존하고 SHA-256을 매니페스트에 기록한다. 정상 원본은 재호출하지 않는다.

## 분류와 조인 원칙

- `fndTp`는 주식형, 채권형, 혼합형, 파생상품, 특별자산 등 거친 자산군으로만 변환한다.
- `prdClsfCd`는 코드북 없이 임의 해석하지 않고 원문을 보존한다.
- 펀드표준코드와 KRX 상장 종목코드는 서로 다른 코드이므로 직접 조인하지 않는다.
- 상품명에서 운용사 접두어, 법정 명칭, 공백, 브랜드 변경만 정규화한다.
- 정규화 이름이 정확히 하나만 일치할 때만 자동 연결한다.
- 복수 후보와 불일치는 각각 `ambiguous`, `unmatched`로 남긴다.
- 금융위 펀드유형만으로 지역, 환헤지, 액티브·패시브를 확정하지 않는다.

## 실행

uv --cache-dir .uv-cache run python -m backend.app.ingestion.fsc_fund
