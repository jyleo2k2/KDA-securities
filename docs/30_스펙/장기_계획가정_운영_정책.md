# 장기 계획가정 운영 정책

> 정책 ID: `long-term-planning-governance-2026-07-22.1`
> 적용 중앙값: `jpm_2026_usd_educational_v2`의 **CMA − 검증 연간비용**
> 상태: 운영·변경통제 확정(수치·계산식 변경 없음)

## 1. 목적과 적용 범위

이 정책은 연금 적립 시나리오를 동일한 기준으로 비교할 때 쓰는 장기 계획가정의
갱신·검토·표시 절차를 정한다. 개별 ETF의 미래수익률을 예측하거나 실제 수익을
보장하는 정책이 아니다.

적용 대상은 `POST /engine/etf-planning-return`,
`POST /engine/etf-planning-assessment`, 교육용 포트폴리오의 장기 계획가정과 이를
설명하는 챗봇·화면이다. 포트폴리오 위험, 글라이드패스, 계좌별 위험자산 한도,
뉴스·거시 기반 전술 판단은 이 정책의 변경 대상이 아니다.

## 2. 고정 운영값

운영 중앙값은 다음 식만 사용한다.

```text
ETF 비용 차감 후 장기 계획가정
= 자산군·지역 CMA − 검증 연간비용
```

- CMA는 현재 승인된 `jpm_2026_usd_educational_v2` 스냅샷을 사용한다. 원천의
  기준일·10~15년 장기 시계·자산군 매핑은 결과와 함께 보존한다.
- 비용은 금융투자협회 `kofia_reported_ter_percent`의 승인된 정확 식별 매칭을 우선한다. 없을 때만
  KIS 공식 총보수율을 사용하며, 둘 다 없으면 해당 ETF의 계획가정 산출을 보류한다.
- 산업 성장·밸류에이션·팩터·통화·모델 불확실성 후보값은 진단용으로만 보존한다.
  운영 중앙값 반영값은 모두 `0%p`다.
- 과거 ETF 수익률, 최신 금리·물가, 뉴스, 과거 유사국면은 CMA나 ETF 비중을 자동으로
  바꾸지 않는다. 거시는 연례 검토를 위한 설명 근거로만 사용한다.

상세 계산·출처·누락 처리 계약은
[ETF 장기 계획수익률 모델](./ETF_장기_계획수익률_모델.md)과
[거시지표 기반 계획가정 검토 계약](./거시지표_계획가정_검토.md)을 따른다.

## 3. 역할과 권한

| 역할 | 권한 | 할 수 없는 일 |
|---|---|---|
| 엔진 오너 김태형 | CMA 수치·매핑·계산식·비용 처리 순서·정책 버전의 승인 또는 기각 | 데이터만 보고 런타임 값을 자동 변경하지 않음 |
| 데이터 운영 담당 | 원천 수집, 기준일·참조·해시 보존, 비용 매칭 품질 확인, 검토 자료 작성 | CMA 값·비용 차감 규칙을 단독 승인하지 않음 |
| 구현 담당 | 승인된 정책 버전을 엔진·API·화면에 반영하고 회귀를 검증 | 정책 밖 보정치·표시 수치를 추가하지 않음 |
| 챗봇·화면 | 엔진 결과·출처·한계를 그대로 설명 | 수치를 재계산하거나 미래 성과를 단정하지 않음 |

수치·계산식·매핑·비용 우선순위를 바꾸는 모든 변경은 엔진 오너의 명시적 승인 전에는
배포하지 않는다. 정책 문구·검토 기록만의 변경도 어떤 수치 변경도 포함하지 않아야 한다.

## 4. 정기 검토와 예외 검토

정기 검토는 현재 승인 정책의 효력 시작일로부터 **12개월 이내에 최소 1회** 실시한다.
새 CMA 원문이 발간되었다는 사실만으로는 자동 갱신하지 않는다.

다음은 정기 일정을 기다리지 않고 검토를 개시하는 사유다.

- CMA 원천의 정정·방법론·자산군 정의 변경
- KOFIA 또는 KIS 비용 원천의 정정, 유일 매칭 훼손, 기준일·식별자 품질 문제
- 입력 스냅샷·출처 칩·결과 버전 보존을 깨는 구현 결함
- 법령·계좌 적격성 정의 변경으로 자산군 매핑의 전제가 사라진 경우

다음은 단독으로 예외 갱신 사유가 아니다: 최근 수익률, 시장 급등락, 기준금리·CPI
발표, 뉴스, 특정 ETF의 단기 성과. 이 항목들은 검토 자료에 기록할 수 있으나 중앙값을
자동 조정하지 않는다.

## 5. 검토·승인·배포 절차

1. 데이터 운영 담당이 원문·기준일·참조·SHA-256·비용 매칭 결과를 보존한 후보
   스냅샷을 만든다. API 키와 개인 계좌 데이터는 기록에 넣지 않는다.
2. 구현 담당은 기존 정책과 후보 정책의 자산군별 CMA, 비용 적용 가능 범위, 누락 ETF,
   120개 교육용 포트폴리오 결과 차이를 비교한다. 단위·기준일·출처가 맞지 않으면
   후보를 기각 또는 보류한다.
3. 수치 또는 계산 변경 후보는 엔진 골든 테스트·관련 API 계약 테스트·전체 엔진 회귀를
   통과하고, 변경 근거·이전 결과 영향·롤백 방법을 포함해 엔진 오너에게 제출한다.
4. 엔진 오너가 승인·기각·보류 중 하나를 명시한다. 승인 시에만 새 정책 버전을 발급하고
   엔진 상수·응답의 `policy_version`·테스트 기준값을 함께 갱신한다.
5. 배포 뒤에는 정책 버전, 엔진 커밋, 입력 스냅샷 식별자, 승인 기록, 결과 비교와 검증
   결과를 변경 이력에 남긴다. 이전 정책 결과는 새 값으로 덮어쓰지 않는다.

검토가 완료되지 않았거나 품질 게이트를 통과하지 못하면 마지막 승인 정책을 유지한다.
비용이 검증되지 않은 개별 ETF는 마지막 값을 추정해 채우지 않고 그 ETF 결과만 보류한다.

## 6. 버전과 재현성

정책 버전은 `YYYY-MM-DD.N` 형식으로 발급한다. 수치·식·매핑·비용 처리 순서가 바뀌면
`N`을 올린 새 버전이 필수다. 같은 정책 버전 안에서의 원천 재수집도 기준일·참조·해시가
바뀌면 새 입력 스냅샷으로 보존한다.

각 결과에는 최소한 아래 정보를 남긴다.

- `policy_version`, `cma_policy_id`, 엔진 버전
- CMA·비용의 `label`, `reference`, `as_of`
- 비용 원천과 누락·대체 사용 경고
- ETF별 운용사·보수합계·기타비용·적용 TER와 포트폴리오 비중가중 연간비용
- 별도 매매·중개수수료의 중앙값 미포함 상태
- `is_forecast=false`, `historical_performance_used=false`,
  `risk_adjustment_included=false`
- 포트폴리오 결과의 비중별 비용 차감 전·후 합계와 적용 가능 비중

## 7. 화면·챗봇 표현 정책

사용자 화면의 제목은 **장기 계획가정**으로 표기한다. `예상수익률`, `수익 보장`,
`목표 달성 가능성`, `확정`, 상·하방 수익률 또는 확률분포 표현을 중앙값에 붙이지 않는다.

결과 카드에는 다음을 함께 보인다.

- `CMA − 검증 연간비용`이라는 계산 기준
- CMA 원천·기준일과 비용 원천·기준일의 출처 칩
- 운용사명, ETF별 적용 TER와 포트폴리오 비중가중 연간비용
- 적용 정책·엔진 버전과 “연 1회 이상 검토” 상태
- 비용 누락으로 산출을 보류한 경우 그 사유
- 위험·스트레스는 장기 계획가정과 분리한 별도 카드라는 안내

챗봇은 “장기 적립 시나리오 비교를 위한 가정이며 미래 성과 예측이 아니다”라는 한계를
먼저 설명한다. 거시 지표나 과거 유사국면을 언급할 때도, 해당 값이 CMA·비중·리밸런싱을
자동 변경하지 않는다는 경계를 유지한다.
