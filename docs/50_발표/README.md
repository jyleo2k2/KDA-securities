## 슬라이드 만들 때
- Mermaid 블록은 GitHub/VS Code/Obsidian에서 렌더된다. 슬라이드에는 렌더 이미지를 캡처해 넣는다.
- 모든 수치는 근거 문서에서 인용했다. 발표 중에는 분모·연도·기준일을 함께 말한다(특히 방치 통계는 분모가 DB+DC+IRP인지 DC만인지 명시).
- 실데이터/목데이터 경계를 슬라이드에도 표기한다(사용자 계좌·소득·납입 = 목데이터).
