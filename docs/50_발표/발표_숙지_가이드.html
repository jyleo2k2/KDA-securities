이 네 질문만은 모두 답하기

왜 LLM이 포트폴리오를 직접 계산하지 않나요?

같은 입력에 같은 결과가 필요해서 수치는 Python 규칙 엔진이 계산합니다. LLM은 검증된 결과를 설명하고, 실패하면 엔진 답변을 유지합니다.

이 서비스가 주문이나 일임까지 하나요?

아닙니다. 자문·정보 제공형 운용 가이드이며 실제 상품 선택과 주문은 이용자가 공식 채널에서 직접 실행합니다. 미래 수익도 보장하지 않습니다.

왜 Python·FastAPI와 Supabase를 선택했나요?

규칙·데이터·RAG·에이전트를 Python 한 환경에서 다루고, 관계가 강한 계좌 데이터를 PostgreSQL로 정규화하기 위해서입니다. Vercel 프론트 밖의 Supabase가 영속 DB·Auth·RLS를 담당합니다.

현재 가장 큰 한계는 무엇인가요?

금융사 실계좌 연동과 주문 실행은 아직 없고, 상시 인프라의 부하·비용·SLA 및 실서비스 규제 절차를 추가 검증해야 합니다.

마지막 체크

반드시 말하기

  • 계산은 규칙 엔진, 설명은 LLM입니다.
  • DC·IRP와 연금저축의 규칙을 섞지 않습니다.
  • 사용자가 이해하고 직접 결정하도록 돕습니다.

단정하지 않기

  • AI가 가장 좋은 상품을 자동으로 골라 준다.
  • 미래 수익이 보장된다.
  • 현재 금융사 계좌 이전이나 주문이 실행된다.
