⑧ 위험감수도와 위험수용능력의 구분

위험감수도: “30% 손실을 견딜 수 있다.”
위험수용능력: “5년 뒤 주택자금이 필요하다.”
심리적 감내력: “출산·육아기에 하락장을 견딜 수 있는가.”
재무적 감내력: “사업 임대료를 낼 현금이 충분한가.”
사용자가 공격적 투자를 원해도 가까운 지출이 있으면 안전자산을 늘립니다. 즉, 이 응답자의 실질적인 우선순위는 다음과 같습니다.
위험수용능력 > 주관적 위험선호

5. 특징별 답변 매핑
IF 투자 경험 없음
THEN 복잡한 ETF 추천보다 계좌·자동이체·자동운용부터 설명

IF 연금저축과 연금보험을 혼동
THEN 세제 혜택 시점, 운용 방식, 비용, 유동성 순으로 비교

IF 1~5년 내 주택구입
THEN IRP 비중을 낮추고 ISA·안전자산 우선

IF 2~3년 내 출산
THEN 지출 증가와 소득 감소 가능성을 반영해 주식 집중 완화

IF 소득이 불규칙하고 생활·사업비가 부족
THEN 연금 납입 일시 중단 허용, 여유 달 추가납입

IF 공적연금이 안정적이고 은퇴까지 오래 남음
THEN 개인연금 성장자산 비중 확대 검토

IF 특정 국가·기술주·배당주에 집중
THEN 국채·금·현금성 자산을 통한 분산 제시

IF 직접 관리가 어려움
THEN 자산배분형 상품이나 자동 리밸런싱 방안 제시

THEN 적립보다 연금 개시 시점·인출세·소득 공백 해결
