# 네이버페이 'Npay 연금' 리서치

> 작성일: 2026-07-23 · 프로젝트: 연금 코파일럿
> 관련: [시장_경쟁.md](./시장_경쟁.md) · [키움_동향.md](./키움_동향.md) · [기획서](../10_기획/기획서.md)

## ★ 핵심 요약

- 2026-07-23 네이버페이가 **'Npay 연금'** 출시. 우리 기획의 핵심 가치 제안과 **정면으로 겹친다**.
- 겹치는 축 5개: 계좌 통합 조회 · AI 맞춤 카드 · 또래 비교 · 연금 계산기 · 3층 연금 안내.
- **그들의 결정적 우위**: 실계좌 연동, 국민연금 포함, 네이버페이 유통망, 우리은행·한국투자증권 상담 연계.
- **우리의 결정적 우위**: ETF 종목 단위 운용 레이어. 공개된 기사·보도자료에 **ETF 언급이 없다**.
- 포지셔닝 결론: **"조회·적립"에서 경쟁하지 말고 "운용"으로 이동한다.**

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 출시일 | 2026-07-23 |
| 사업자 | 네이버페이 |
| 진입 경로 | 네이버페이 금융 홈 → '연금' · '내 자산' · 'MY 연금' |
| 포괄 범위 | 국민연금 · 퇴직연금(DC) · IRP · 개인연금 (DB형은 예상 퇴직금 수동 입력) |
| 제휴 | 우리은행(IRP 상담·가입), 한국투자증권(1:1 맞춤형 연금 컨설팅) |
| 한 줄 정의 | 흩어진 연금 자산을 모아 AI와 또래 데이터로 노후 준비 수준에 맞는 관리 솔루션 제공 |

## 2. 공개된 기능 (우리 기획과 대조)

| Npay 연금 기능 | 내용 | 우리 기획과의 관계 |
|---|---|---|
| 연금 통합 조회 | 여러 기관·금융사에 흩어진 연금 자산 집계. **국민연금 포함** | **정면 충돌**. 우리 1번 가치인데 실계좌로 무료 제공 |
| AI 맞춤 솔루션 카드 | 자산 현황을 AI로 분석해 **메시지 카드** 형태 제공 | **겹침**. 우리 챗봇 추천 카드와 동일 개념 |
| 또래 비교 | 동일 연령대 **상위 30%** 사용자와 비교 | **겹침**. 우리 익명 벤치마크(1만 명 통계)와 동일 |
| 연금 계산기 | 목표 은퇴 생활비 입력 → 추가 납입금·목표 수익률 안내 | **겹침**. 세제 정밀도는 우리가 더 높음 |
| 3층 연금탑 콘텐츠 | 개인연금 상품이 없는 사용자에게 교육 콘텐츠 연결 | **겹침** |
| 전문가 상담 연계 | 수령액 부족·수익률 변동 시 우리은행·한투 무료 상담 연결 | **우리엔 없음**. 자문 이후 실행으로 잇는 고리 |
| ETF 종목 분석·추천 | **공개 자료에 언급 없음** | **우리 고유 영역** |

## 3. 우리가 앞서는 것

| 항목 | 내용 |
|---|---|
| ETF 운용 레이어 | 연금 적격 ETF 861종을 계좌별로 분류(DC 823·IRP 823·연금저축 861). 15년 총수익 이력, 배당 분배 이벤트 보유 |
| 계좌별 규칙 엔진 | DC·IRP 위험자산 70% 한도, 연금저축 총량 한도 없음 등 계좌 규칙을 코드로 강제 |
| Explainable by Design | 규칙 엔진이 계산하고 LLM은 서술만. 모든 수치에 출처 칩. Npay의 "AI 분석"은 근거 제시 구조가 공개되지 않음 |
| 대화형 Q&A | Npay는 메시지 카드 단방향. 우리는 되물을 수 있음 |
| 세제 정밀도 | 연령별 5.5/4.4/3.3%, 1,500만원 룰, 수령한도까지 반영 |

요약하면 Npay는 **"얼마 모였고 얼마 더 넣어야 하나"(적립 관점)**, 우리는 **"그 돈으로 무엇을 사서 어떻게 굴리나"(운용 관점)**다.

## 4. 그들이 앞서는 것 (인정할 부분)

| 항목 | 내용 |
|---|---|
| 실계좌 연동 | 우리는 목데이터 표시 전용이며 "실제 계좌 연결·이전·자동매매 없음"을 고지한다. 개인 프로젝트가 넘기 어려운 벽 |
| 국민연금 포함 | 우리는 사적연금 3종만 다뤄 3층 중 1층이 비어 있다. 노후 자산 전체 그림은 Npay가 완성형 |
| 유통·실행 연결 | 네이버페이 사용자 기반 + 우리은행 IRP 가입·한투 1:1 컨설팅으로 실행까지 연결 |
| DB형 커버 | 수동 입력이지만 DB형까지 포함 |

## 5. 시사점과 액션

1. **포지셔닝을 운용 레이어로 이동한다.** "통합 조회·비교"를 전면에 내세우면 "네이버페이가 무료로 하는데?"가 된다. 첫 문장을 "모인 돈을 어떤 ETF로 어떻게 굴릴지"로 잡는다.
2. **또래 비교 기능을 재평가한다.** 대기업이 핵심 기능으로 채택했다는 것은 사용자에게 통한다는 신호다. 우리는 1만 명 통계 데이터와 `/benchmark/summary`를 이미 보유하고 있어 복원 비용이 낮다. (2026-07-23 기준 화면만 제거된 상태)
3. **국민연금 부재를 스코프로 명시하거나 최소 입력을 받는다.** Npay가 DB형을 수동 입력으로 채운 방식을 참고할 수 있다. 다루지 않을 경우 발표에서 "사적연금 운용에 집중"을 먼저 선언한다.
4. **경쟁사 등장은 시장 검증 신호로 활용한다.** 같은 날 대형 플랫폼이 같은 문제의식으로 출시했다는 것은 방향이 맞았다는 근거다. 다만 그들은 적립까지, 우리는 운용까지 간다는 대비로 설명한다.
